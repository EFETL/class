康軒版1-1　國語（康軒版）第二次段考
對應單元第五～八課；生活與自然觀察類課文（字音字形、部首、詞語、標點、譬喻、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「彎」腰 ㄨㄢ
  2. (B)「屋」頂 ㄨˊ
  3. (C)「鮮」豔 ㄒㄧㄢˇ
  4. (D)「灑」水 ㄙㄚ
答案：(A)
解析：彎腰讀ㄨㄢ（一聲）。屋頂的屋讀ㄨ（一聲）、鮮豔的鮮讀ㄒㄧㄢ（一聲）、灑水的灑讀ㄙㄚˇ（三聲），其餘三個都標錯了。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)五顏六色
  2. (B)五言六色
  3. (C)五顏六式
  4. (D)五嚴六色
答案：(A)
解析：「五顏六色」形容色彩繁多，顏是頁部（和頭臉有關），不能寫成「言」或「嚴」。
3請把注音寫成國字：秋天一到，農夫忙著ㄕㄡ　ㄍㄜ（　　）稻子，田裡一片ㄐㄧㄣ　ㄏㄨㄤˊ（　　）。
答案：收割、金黃
解析：「收割」的割是刀部；「金黃」的黃不要少寫中間一橫。
4「湖」這個字的部首是什麼？
  1. (A)水（氵）
  2. (B)古
  3. (C)月
  4. (D)口
答案：(A)
解析：「湖」和水有關，部首取三點水（水部），右邊的「胡」是聲符。
5下列量詞使用正確的是哪一個？
  1. (A)一「面」鏡子
  2. (B)一「條」帽子
  3. (C)一「棵」船
  4. (D)一「隻」教室
答案：(A)
解析：鏡子用「面」。帽子用「頂」、船用「艘」、教室用「間」。
6「小河唱著歌，一路往前跑。」這句話使用了什麼修辭？
  1. (A)擬人
  2. (B)譬喻
  3. (C)誇飾
  4. (D)排比
答案：(A)
解析：「唱歌」「跑」都是人的動作，把小河當成人來寫，屬於擬人。
7請為下面的句子加上正確的標點符號（寫出完整句子）：　哇　這片楓葉好紅啊
答案：哇！這片楓葉好紅啊！
解析：「哇」是感嘆詞，後面用驚嘆號；整句在讚嘆，句末也用驚嘆號。
8「天空藍得像一片大海。」這句話中的「像」，表示什麼？
  1. (A)把天空比作大海
  2. (B)天空真的是大海
  3. (C)天空在大海上面
  4. (D)天空和大海一樣大
答案：(A)
解析：「像」是喻詞，把天空（喻體）比作大海（喻依），是譬喻修辭，不是說它真的是大海。
9請用「一……就……」造一個完整的句子。
答案：參考答案：我一放學回家，就先把功課寫完。
解析：「一……就……」表示前一件事發生後，後一件事馬上跟著發生，前後要各接一個動作。
閱讀測驗（第 10～11 題）
　　學校旁邊有一條小水溝，以前總是黑黑臭臭的，大家經過都捏著鼻子快步走過。
　　後來社區的叔叔阿姨們一起清淤泥、種水生植物，還在旁邊立了牌子，提醒大家不要亂丟垃圾。過了一個夏天，水變清了，居然有小魚游來游去。
　　現在放學經過那裡，我常常停下來看一看。原來，臭水溝也可以變成小溪。
10小水溝為什麼會變乾淨？
  1. (A)因為社區居民一起清淤泥、種水生植物
  2. (B)因為下了很多雨
  3. (C)因為政府把水溝填起來了
  4. (D)因為小魚把垃圾吃掉了
答案：(A)
解析：第二段說社區的叔叔阿姨一起清淤泥、種水生植物並立牌提醒，水才變乾淨。
11「原來，臭水溝也可以變成小溪。」這句話最主要想表達什麼？
  1. (A)只要大家一起努力，環境是可以改變的
  2. (B)小溪和水溝是同一種東西
  3. (C)水溝一定會自己變乾淨
  4. (D)小魚很喜歡住在水溝裡
答案：(A)
解析：整篇在寫居民共同行動帶來的改變，最後一句是作者的感想，強調努力能改善環境。
南一版1-2　國語（南一版）第二次段考
對應單元第五～八課；家庭與節慶類課文（字音字形、反義詞、關聯詞、標點、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「暖」和 ㄋㄨㄢˇ
  2. (B)「靜」悄悄 ㄐㄧㄥ
  3. (C)「拾」起 ㄕˇ
  4. (D)「圍」爐 ㄨㄟˇ
答案：(A)
解析：暖和讀ㄋㄨㄢˇ。靜讀ㄐㄧㄥˋ、拾讀ㄕˊ、圍讀ㄨㄟˊ，其餘三個聲調都標錯了。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)熱鬧非凡
  2. (B)熱鬧非幾
  3. (C)熱鬧飛凡
  4. (D)熱鬧非幾凡
答案：(A)
解析：「非凡」是不平凡的意思，凡不能寫成「幾」，非也不能寫成「飛」。
3請把注音寫成國字：過年時，家家戶戶ㄊㄧㄝ（　　）春聯，到處都是ㄒㄧˇ　ㄑㄧˋ（　　）洋洋的氣氛。
答案：貼、喜氣
解析：「貼」是貝部（和財物有關的動作）；「喜氣」的喜下面是「口」。
4「寒冷」的相反詞是下列哪一個？
  1. (A)溫暖
  2. (B)涼爽
  3. (C)潮溼
  4. (D)陰暗
答案：(A)
解析：寒冷是很冷，相反是溫暖。涼爽偏涼、潮溼講水氣、陰暗講光線，都不是相反詞。
5請填入合適的關聯詞語：（　　　）下雨了，我們（　　　）改在教室裡活動。
答案：因為、所以
解析：前面是原因（下雨），後面是結果（改在教室），用「因為……所以……」。
6下列哪一句沒有使用擬人修辭？
  1. (A)山坡上開滿了黃色的小花。
  2. (B)風輕輕地拍著我的肩膀。
  3. (C)太陽公公探出頭來了。
  4. (D)小樹苗努力地向上長。
答案：(A)
解析：第一句只是單純描寫景物；其餘三句都把風、太陽、小樹苗當成人來寫。
7下列句子的標點符號，使用正確的是哪一句？
  1. (A)奶奶說：「明天早點回來。」
  2. (B)奶奶說「明天早點回來。」：
  3. (C)奶奶說：明天早點回來「」
  4. (D)奶奶說，「明天早點回來」。
答案：(A)
解析：引述說話內容要先用冒號再用引號，句號放在下引號的裡面。
8「全家人圍在一起吃團圓飯」，這最可能是哪一個節日？
  1. (A)除夕
  2. (B)清明節
  3. (C)端午節
  4. (D)兒童節
答案：(A)
解析：除夕夜全家團聚吃年夜飯（團圓飯）是最重要的習俗。
9請用「有的……有的……」造一個完整的句子。
答案：參考答案：下課時，同學們有的在打球，有的在看書。
解析：「有的……有的……」用來列舉不同的人或事物在做的事，前後要各接一個情形。

11奶奶說「沒關係，煮熟了都一樣圓。」，可以看出奶奶是一個什麼樣的人？
  1. (A)包容、不苛求的人

1下列「」中的字，注音正確的是哪一個？
  1. (A)「掃」地 ㄙㄠˇ
  2. (B)「露」出 ㄌㄡˋ
  3. (C)「參」加 ㄘㄣ
  4. (D)「奔」跑 ㄅㄣˋ
答案：(A)
解析：掃地讀ㄙㄠˇ。露出的露讀ㄌㄨˋ、參加的參讀ㄘㄢ、奔跑的奔讀ㄅㄣ（一聲）。
2「聽」這個字一共有幾畫？
  1. (A)二十二畫
  2. (B)二十畫
  3. (C)十八畫
  4. (D)二十四畫
答案：(A)
解析：「聽」共 22 畫，部首是耳部。筆畫多的字要分成左右兩邊慢慢數。
3請寫出「」中字的注音：冬天的清晨，湖面上飄著一層薄薄的「霧」，遠山變得很「朦」朧。
答案：霧ㄨˋ、朦ㄇㄥˊ
解析：「霧」讀ㄨˋ，雨部；「朦朧」讀ㄇㄥˊ ㄌㄨㄥˊ，形容看不清楚的樣子。
4「一年四季」依照順序排列，正確的是哪一個？
  1. (A)春、夏、秋、冬
  2. (B)春、秋、夏、冬
  3. (C)冬、春、夏、秋
  4. (D)夏、春、秋、冬
答案：(A)
解析：四季順序是春夏秋冬，一年循環一次。
5「他做事很認真，總是（　　）。」括號中填入哪一個成語最恰當？
  1. (A)全力以赴
  2. (B)半途而廢
  3. (C)三心二意
  4. (D)馬馬虎虎
答案：(A)
解析：前面說他很認真，要填意思相合的「全力以赴」；其餘三個都是不認真的意思。
