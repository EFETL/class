編輯說明

一、這本書是什麼。 這是小三的第 1 回綜合練習題本。國語、數學、自然、社會各依 康軒、南一、翰林 分節，英語再加上 何嘉仁，每一節都是 30 題，可以單獨當成一份小考。第 1 回與第 2 回的題目完全不重複。

二、題目從哪裡來。 全書題目 100% 自編，沒有抄錄任何學校的段考原卷。命題範圍參考「中小學題庫網」上北中南九校的段考紀錄與十二年國教課綱。數學題的答案與解析由程式計算並逐題驗算；國語、自然、社會、英語則由概念表展開，並以程式檢查選項不重複、答案索引正確、同年級題目零重複。

三、三個版本有什麼不同。 四家出版社依同一份課綱編寫，概念相同、單元順序與取材不同。因此本書讓三（四）節涵蓋不同的字詞、概念與例子，孩子做完自己版本那一節後，其他節可以直接當成補充練習。

四、怎麼使用。 螢幕上點每題下方的「解析」可展開答案與說明；按上方「列印 / 存成 PDF」時解析會自動隱藏，印出來就是乾淨的作答題本，答案統一收在書末「解答本」。列印請用 Chrome 或 Edge，頁碼才會出現在頁尾。

五、配分建議。 每一節 30 題、每題 3 分共 90 分，作答工整 10 分，滿分 100 分。建議作答時間每節 40 分鐘。長篇閱讀測驗請搭配同年級的「段考題本」使用。

1「重新」的「重」讀作什麼？
  1. (A)ㄔㄨㄥˊ
  2. (B)ㄓㄨㄥˇ
  3. (C)ㄐㄧㄢ
  4. (D)ㄔㄨㄢˊ
答案：(A)
解析：「重」是破音字：重新 讀 ㄔㄨㄥˊ、重量 讀 ㄓㄨㄥˋ。
2「心愿」這個詞寫錯了，正確的寫法是什麼？
  1. (A)心愿
  2. (B)心願
  3. (C)心愿？
  4. (D)以上皆非
答案：(B)
解析：願是「願望」，不能寫成「愿」，正確寫法是「心願」。
3「稻田像一張鋪到天邊的金黃色地毯。」這句話使用了什麼修辭？
  1. (A)排比
  2. (B)摹寫
  3. (C)譬喻
  4. (D)以上皆非
答案：(C)
解析：有喻體、喻詞「像」和喻依，所以是譬喻。
4下列哪一句沒有使用誇飾？
  1. (A)他的房間亂得可以養魚了。
  2. (B)難道我們就這樣放棄嗎？
  3. (C)以上皆非
  4. (D)溪水淙淙，像有人在遠處彈琴。
答案：(D)
解析：「溪水淙淙，像有人在遠處彈琴。」用的是摹寫，不是誇飾。
5「高興」的近義詞是下列哪一個？
  1. (A)愉快
  2. (B)馬虎
  3. (C)困難
  4. (D)驕傲
答案：(A)
解析：高興和愉快意思相近；難過才是它的相反詞。
6下面這句話有語病，請改寫成通順的句子：　為了避免不再發生意外，學校加強宣導。
答案：為了避免再發生意外，學校加強宣導。
解析：「避免」和「不再」兩個否定疊在一起，意思相反了。
7「迫不急待」這個詞寫錯了，正確的寫法是什麼？
  1. (A)迫不急待
  2. (B)迫不急待？
  3. (C)迫不及待
  4. (D)以上皆非
答案：(C)
解析：及是「來得及」的及，正確寫法是「迫不及待」。
8「小草在風中向我們招手。」這句話使用了什麼修辭？

  4. (D)以上皆非
