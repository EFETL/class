康軒版1-1　國語（康軒版）第一次段考
對應單元第一～四課；主題多為校園生活與自然觀察（字詞、量詞、標點、擬人修辭、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)微風輕「拂」ㄈㄨˊ
  2. (B)一片「稻」田 ㄊㄠˊ
  3. (C)「攤」開地圖 ㄊㄢˇ
  4. (D)一「盞」小燈 ㄓㄢˋ
答案：(A)
解析：拂讀ㄈㄨˊ，正確。稻讀ㄉㄠˋ、攤讀ㄊㄢ（一聲）、盞讀ㄓㄢˇ（三聲），其餘三個都標錯了。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)完成心愿
  2. (B)迫不急待
  3. (C)興高采烈
  4. (D)專心至志
答案：(C)
解析：「興高采烈」正確。心愿→心願；迫不急待→迫不及待（來不及等待）；專心至志→專心致志（致，把心力用到某處）。
3請把注音寫成國字：小明ㄗˇ　ㄒㄧˋ（　　）地ㄍㄨㄢ　ㄔㄚˊ（　　）葉子的形狀，還畫下來做紀錄。
答案：仔細、觀察
解析：ㄗˇㄒㄧˋ是「仔細」（仔的部首是人部）；ㄍㄨㄢㄔㄚˊ是「觀察」，注意「察」是宀部，不要寫成「查」。
4下列量詞使用正確的是哪一個？
  1. (A)一「畝」稻田
  2. (B)一「棵」小鳥
  3. (C)一「條」教室
  4. (D)一「片」故事書
答案：(A)
解析：田地用「畝」。小鳥用「隻」、教室用「間」、故事書用「本」。
5「聞」這個字的部首是什麼？
  1. (A)門
  2. (B)耳
  3. (C)日
  4. (D)口
答案：(B)
解析：「聞」是用耳朵聽，部首取「耳」，門只是外框（聲符）。查字典時要先找耳部，再數 8 畫。
6「上課鐘響了，同學們（　　）地回到座位上。」括號中填入哪一個詞語最恰當？
  1. (A)井然有序
  2. (B)七手八腳
  3. (C)無精打采
  4. (D)自言自語
答案：(A)
解析：井然有序＝很整齊、有秩序，最符合聽到鐘聲回座位的情形。七手八腳是慌亂、無精打采是沒有精神、自言自語是自己對自己說話，都不合句意。
7請為這個句子加上正確的標點符號（寫出完整句子）：　媽媽問我　今天在學校過得好嗎
答案：媽媽問我：「今天在學校過得好嗎？」
解析：說話的內容要先用冒號（：）再用引號（「」）框起來；句子在問人，所以引號裡用問號（？），問號要放在下引號的裡面。
8「小草在風中向我們招手。」這句話使用了什麼修辭法？
  1. (A)譬喻
  2. (B)擬人
  3. (C)誇飾
  4. (D)排比
答案：(B)
解析：「招手」是人的動作，作者把小草當成人來寫，所以是擬人。譬喻要有「像、好像、彷彿」等喻詞。
9請用「一邊……一邊……」造一個完整的句子。
答案：參考答案：妹妹一邊哼著歌，一邊幫忙擦桌子。
解析：「一邊……一邊……」用來表示兩件事同時進行，前後要各接一個動作，句末別忘了加句號。
閱讀測驗（第 9～10 題）
　　學校中庭有一棵老榕樹，它的鬍鬚長長地垂下來，像一位慈祥的老公公。下課鐘一響，我們就跑到樹下玩。有人在樹蔭裡看書，有人蹲著看螞蟻搬東西。
　　有一天，我發現榕樹的葉子上有一個小小的洞，仔細一看，原來是毛毛蟲把葉子當成午餐了。老師說：「這也是大自然的一部分喔！」從那天起，我每天下課都會去看看那隻毛毛蟲，看牠什麼時候會變成蝴蝶。
10短文中把老榕樹比喻成什麼？
  1. (A)一位慈祥的老公公
  2. (B)一把大雨傘
  3. (C)一隻毛毛蟲
  4. (D)一座小山
答案：(A)
解析：第一段寫「它的鬍鬚長長地垂下來，像一位慈祥的老公公」，有喻詞「像」，是譬喻修辭。
11根據短文，葉子上的小洞是怎麼來的？
  1. (A)被風吹破的
  2. (B)毛毛蟲吃出來的
  3. (C)同學不小心弄破的
  4. (D)太陽晒出來的
答案：(B)
解析：第二段說「原來是毛毛蟲把葉子當成午餐了」，表示洞是毛毛蟲啃出來的。
南一版1-2　國語（南一版）第一次段考
對應單元第一～四課；主題多為家庭生活與節慶（字音字形、反義詞、關聯詞、照樣寫句子、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)「著」急 ㄓㄠˊ
  2. (B)「相」片 ㄒㄧㄤ
  3. (C)「散」步 ㄙㄢˇ
  4. (D)「重」新 ㄓㄨㄥˋ
答案：(A)
解析：著急讀ㄓㄠˊ ㄐㄧˊ。相片的相讀ㄒㄧㄤˋ、散步的散讀ㄙㄢˋ、重新的重讀ㄔㄨㄥˊ，這三個都是常見的破音字。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)心情愉快
  2. (B)一模一羊
  3. (C)按步就班
  4. (D)不知所錯
答案：(A)
解析：一模一羊→一模一樣；按步就班→按部就班（部，次序）；不知所錯→不知所措（措，安排、處置）。
3請把注音寫成國字：比賽得到第一名時，大家ㄏㄨㄢ　ㄏㄨ（　　）；上台前，我的心情很ㄐㄧㄣˇ　ㄓㄤ（　　）。
答案：歡呼、緊張
解析：ㄏㄨㄢㄏㄨ是「歡呼」（呼是口部）；ㄐㄧㄣˇㄓㄤ是「緊張」，「緊」下面是「糸」，不要少寫一橫。
4下列量詞使用正確的是哪一個？
  1. (A)一「艘」輪船
  2. (B)一「頭」蝴蝶
  3. (C)一「顆」道路
  4. (D)一「支」玫瑰花
答案：(A)
解析：船用「艘」。蝴蝶用「隻」、道路用「條」、花用「朵」。
5「照」這個字的部首是什麼？
  1. (A)日
  2. (B)火（灬）
  3. (C)刀
  4. (D)口
答案：(B)
解析：「照」下面的四點「灬」就是火部，和火有關（照亮）。上面的「昭」是聲符，不是部首。
6「炎熱」的相反詞是下列哪一個？
  1. (A)寒冷
  2. (B)溫暖
  3. (C)潮溼
  4. (D)悶熱
答案：(A)
解析：炎熱是很熱，相反是很冷，也就是「寒冷」。溫暖、悶熱都還是偏熱；潮溼講的是水氣，不是溫度。
7請填入合適的關聯詞語，讓句子通順：（　　）今天下大雨，（　　）運動會延期舉行。
答案：因為、所以
解析：前面是原因（下大雨），後面是結果（延期），要用「因為……所以……」這組表示因果的關聯詞。
8下列句子中，沒有使用譬喻修辭的是哪一句？
  1. (A)月亮像一艘小船。
  2. (B)他的臉紅得像蘋果。
  3. (C)天空飄著幾朵白雲。
  4. (D)雪花好像棉絮一樣落下來。
答案：(C)
解析：譬喻要有喻詞（像、好像、彷彿）並拿另一種事物來比。第三句只是單純描寫景物，沒有比喻。
9照樣寫句子：他高興得跳了起來。→ 弟弟餓得＿＿＿＿＿＿＿＿＿。
答案：參考答案：弟弟餓得肚子咕嚕咕嚕叫。
解析：「……得……」的句型，前面是狀態（餓），後面要補上被這個狀態引起的樣子或動作，句子才完整。
閱讀測驗（第 9～10 題）
　　中秋節的晚上，我們全家在陽台上烤肉。爺爺一邊翻著香腸，一邊說起他小時候的中秋節：那時候沒有烤肉架，大家就搬張板凳坐在門口，吃著月餅、剝著文旦，抬頭看月亮。
　　我問爺爺：「那樣不會很無聊嗎？」爺爺笑著說：「不會啊，因為大家都在旁邊。」我抬頭看了看月亮，又看了看身邊的家人，好像有點懂了。
10爺爺小時候過中秋節時，沒有做下面哪一件事？
  1. (A)吃月餅
  2. (B)剝文旦
  3. (C)看月亮
  4. (D)烤香腸
答案：(D)
解析：文中說爺爺小時候「沒有烤肉架」，烤香腸是現在全家在陽台上做的事，不是爺爺小時候的活動。
11「我抬頭看了看月亮，又看了看身邊的家人，好像有點懂了。」作者懂了什麼？
  1. (A)月餅比文旦好吃
  2. (B)中秋節重要的是家人在一起
  3. (C)烤肉比看月亮好玩
  4. (D)爺爺以前的生活很無聊
答案：(B)
解析：爺爺說「不會啊，因為大家都在旁邊」，重點在家人團聚，所以作者懂的是中秋節真正重要的是一家人在一起。
翰林版1-3　國語（翰林版）第一次段考
對應單元第一～四課；主題多為四季景物與生活體驗（字音字形、筆畫部首、成語、造句、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)「處」理事情 ㄔㄨˇ
  2. (B)「解」開繩子 ㄐㄧㄝ
  3. (C)「應」該 ㄧㄥˋ
  4. (D)「量」體溫 ㄌㄧㄤˋ
答案：(A)
解析：處理讀ㄔㄨˇ ㄌㄧˇ。解讀ㄐㄧㄝˇ、應該的應讀ㄧㄥ（一聲）、量體溫的量讀ㄌㄧㄤˊ（二聲），都是破音字要特別注意。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)座位安排
  2. (B)隨心所慾
  3. (C)再接再勵
  4. (D)名列前矛
答案：(A)
