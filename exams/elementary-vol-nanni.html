國語1-1　國語　三年級上學期 第一次段考
對應單元第一～四課；主題多為家庭生活與節慶（字音字形、反義詞、關聯詞、照樣寫句子、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)「著」急 ㄓㄠˊ
  2. (B)「相」片 ㄒㄧㄤ
  3. (C)「散」步 ㄙㄢˇ
  4. (D)「重」新 ㄓㄨㄥˋ
答案：(A)
解析：著急讀ㄓㄠˊ ㄐㄧˊ。相片的相讀ㄒㄧㄤˋ、散步的散讀ㄙㄢˋ、重新的重讀ㄔㄨㄥˊ，這三個都是常見的破音字。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)心情愉快
  2. (B)一模一羊
  3. (C)按步就班
  4. (D)不知所錯
答案：(A)
解析：一模一羊→一模一樣；按步就班→按部就班（部，次序）；不知所錯→不知所措（措，安排、處置）。
3請把注音寫成國字：比賽得到第一名時，大家ㄏㄨㄢ　ㄏㄨ（　　）；上台前，我的心情很ㄐㄧㄣˇ　ㄓㄤ（　　）。
答案：歡呼、緊張
解析：ㄏㄨㄢㄏㄨ是「歡呼」（呼是口部）；ㄐㄧㄣˇㄓㄤ是「緊張」，「緊」下面是「糸」，不要少寫一橫。
4下列量詞使用正確的是哪一個？
  1. (A)一「艘」輪船
  2. (B)一「頭」蝴蝶
  3. (C)一「顆」道路
  4. (D)一「支」玫瑰花
答案：(A)
解析：船用「艘」。蝴蝶用「隻」、道路用「條」、花用「朵」。
5「照」這個字的部首是什麼？
  1. (A)日
  2. (B)火（灬）
  3. (C)刀
  4. (D)口
答案：(B)
解析：「照」下面的四點「灬」就是火部，和火有關（照亮）。上面的「昭」是聲符，不是部首。
6「炎熱」的相反詞是下列哪一個？
  1. (A)寒冷
  2. (B)溫暖
  3. (C)潮溼
  4. (D)悶熱
答案：(A)
解析：炎熱是很熱，相反是很冷，也就是「寒冷」。溫暖、悶熱都還是偏熱；潮溼講的是水氣，不是溫度。
7請填入合適的關聯詞語，讓句子通順：（　　）今天下大雨，（　　）運動會延期舉行。
答案：因為、所以
解析：前面是原因（下大雨），後面是結果（延期），要用「因為……所以……」這組表示因果的關聯詞。
8下列句子中，沒有使用譬喻修辭的是哪一句？
  1. (A)月亮像一艘小船。
  2. (B)他的臉紅得像蘋果。
  3. (C)天空飄著幾朵白雲。
  4. (D)雪花好像棉絮一樣落下來。
答案：(C)
解析：譬喻要有喻詞（像、好像、彷彿）並拿另一種事物來比。第三句只是單純描寫景物，沒有比喻。
9照樣寫句子：他高興得跳了起來。→ 弟弟餓得＿＿＿＿＿＿＿＿＿。
答案：參考答案：弟弟餓得肚子咕嚕咕嚕叫。
解析：「……得……」的句型，前面是狀態（餓），後面要補上被這個狀態引起的樣子或動作，句子才完整。
閱讀測驗（第 9～10 題）
　　中秋節的晚上，我們全家在陽台上烤肉。爺爺一邊翻著香腸，一邊說起他小時候的中秋節：那時候沒有烤肉架，大家就搬張板凳坐在門口，吃著月餅、剝著文旦，抬頭看月亮。
　　我問爺爺：「那樣不會很無聊嗎？」爺爺笑著說：「不會啊，因為大家都在旁邊。」我抬頭看了看月亮，又看了看身邊的家人，好像有點懂了。
10爺爺小時候過中秋節時，沒有做下面哪一件事？
  1. (A)吃月餅
  2. (B)剝文旦
  3. (C)看月亮
  4. (D)烤香腸
答案：(D)
解析：文中說爺爺小時候「沒有烤肉架」，烤香腸是現在全家在陽台上做的事，不是爺爺小時候的活動。
11「我抬頭看了看月亮，又看了看身邊的家人，好像有點懂了。」作者懂了什麼？
  1. (A)月餅比文旦好吃
  2. (B)中秋節重要的是家人在一起
  3. (C)烤肉比看月亮好玩
  4. (D)爺爺以前的生活很無聊
答案：(B)
解析：爺爺說「不會啊，因為大家都在旁邊」，重點在家人團聚，所以作者懂的是中秋節真正重要的是一家人在一起。

3把 4909、4990、4099、4919 由小到大排列，正確的是哪一個？
  1. (A)4099 ＜ 4909 ＜ 4919 ＜ 4990
  2. (B)4099 ＜ 4919 ＜ 4909 ＜ 4990

  4. (D)4990 ＜ 4919 ＜ 4909 ＜ 4099

對應單元第一單元 植物的身體（校園植物觀察、莖與葉的比較、分類）　配分選擇每題 8 分、填充每格 5 分、簡答每題 10 分
1下列哪一個不是植物的六大器官之一？
  1. (A)根
  2. (B)莖
  3. (C)葉脈
  4. (D)種子
答案：(C)
解析：六大器官是根、莖、葉、花、果實、種子。葉脈只是葉子裡面的構造，不算獨立的器官。
2甘蔗和竹子的莖上都有一節一節的構造，這個構造叫做什麼？
  1. (A)節
  2. (B)刺
  3. (C)葉柄
  4. (D)根毛
答案：(A)
解析：莖上一圈一圈的地方叫「節」，節上通常會長出葉子或芽。甘蔗、竹子都是有明顯節的莖。
3仙人掌生長在很乾的沙漠，它的莖又肥又厚，主要功能是＿＿＿＿＿＿＿＿。
答案：儲存水分
解析：仙人掌把葉子變成刺以減少水分散失，改用肥厚的莖儲水，並由莖代替葉子製造養分。
4下列哪一組食物，我們吃的都是植物的葉？
  1. (A)高麗菜、菠菜
  2. (B)胡蘿蔔、白蘿蔔
  3. (C)花椰菜、金針花
  4. (D)蘋果、番茄
答案：(A)
解析：高麗菜、菠菜吃的是葉；胡蘿蔔、白蘿蔔是根；花椰菜、金針花是花；蘋果、番茄是果實。
5想要比較兩片葉子的大小，最適合使用下列哪一種工具？
  1. (A)放大鏡
  2. (B)直尺
  3. (C)溫度計
  4. (D)磁鐵
答案：(B)
解析：比較大小要用能量長度的工具，也就是直尺（或方格紙）。放大鏡是看細節、溫度計量溫度，都不能量大小。
6把校園植物分成「葉緣有鋸齒」和「葉緣平滑」兩堆，這種依照特徵把東西分成幾類的方法，叫做＿＿＿＿。
答案：分類
解析：分類要先訂出一個大家都判斷得出來的標準（例如葉緣、葉脈、有沒有毛），同一個標準才能分得清楚。
7下列有關植物「花」的敘述，何者正確？
  1. (A)花的主要功能是吸收水分
  2. (B)花會發育成果實，裡面有種子
  3. (C)所有的花都一定是紅色的
  4. (D)花是植物用來支撐身體的部位
答案：(B)
解析：花是植物繁殖的器官，授粉後子房發育成果實，種子在果實裡。吸水靠根、支撐靠莖，花的顏色更是各式各樣。
8小明把一株鳳仙花插在紅色的水中，過一段時間後把莖橫切開來，最可能看到什麼？
  1. (A)莖裡面出現一點一點的紅色
  2. (B)整條莖都變成黑色
  3. (C)莖完全沒有變化
  4. (D)莖裡面變成綠色
答案：(A)
解析：莖裡有運送水分的管子，紅色的水被吸上來後會留在這些管子裡，橫切面就會看到紅色的小點，證明莖有運輸功能。
9為什麼下大雨過後，很多植物還是站得好好的，不會被沖走？請用「根」來說明。
