編輯說明

康軒版1-1　國語（康軒版）第一次段考
對應單元第一～四課；記敘與生活類課文（字音字形、量詞、成語、譬喻與擬人、關聯詞、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「盡」力 ㄐㄧㄣˋ
  2. (B)「重」複 ㄓㄨㄥˋ
  3. (C)「相」信 ㄒㄧㄤˋ
  4. (D)「散」開 ㄙㄢˇ
答案：(A)
解析：盡力讀ㄐㄧㄣˋ。重複讀ㄔㄨㄥˊ、相信讀ㄒㄧㄤ、散開讀ㄙㄢˋ，其餘三個都標錯了。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)聚精會神
  2. (B)全神灌注
  3. (C)專心至致
  4. (D)目不轉精
答案：(A)
解析：全神灌注→全神貫注（貫是貫穿）；專心至致→專心致志；目不轉精→目不轉睛（睛是眼睛）。
3請把注音寫成國字：他ㄏㄠˊ　ㄅㄨˋ（　　）猶豫地舉手，ㄩㄥˇ　ㄍㄢˇ（　　）說出自己的想法。
答案：毫不、勇敢
解析：「毫不」的毫是細毛，表示一點也不；「勇敢」的勇是力部，敢是攴部。
4下列量詞使用正確的是哪一個？
  1. (A)一「首」歌
  2. (B)一「棵」魚
  3. (C)一「條」書
  4. (D)一「張」樹
答案：(A)
解析：歌用「首」。魚用「條」、書用「本」、樹用「棵」。
5「他做事總是（　　），從來不馬虎。」括號中填入哪一個成語最恰當？
  1. (A)一絲不苟
  2. (B)得過且過
  3. (C)馬馬虎虎
  4. (D)三心二意
答案：(A)
解析：後句說「不馬虎」，前面要填意思相合的「一絲不苟」（做事非常仔細）。
6「陽光把操場曬得發燙，連影子都躲起來了。」這句話使用了什麼修辭？
  1. (A)擬人
  2. (B)譬喻
  3. (C)排比
  4. (D)設問
答案：(A)
解析：「影子躲起來」是人的動作，把影子當成人來寫，屬於擬人。
7請填入合適的關聯詞語：（　　　）他每天練習，（　　　）進步得特別快。
答案：因為、所以
解析：前面是原因（每天練習），後面是結果（進步快），用「因為……所以……」。
8下列句子的標點符號，使用正確的是哪一句？
  1. (A)老師問我們：「今天的作業寫完了嗎？」
  2. (B)老師問我們「今天的作業寫完了嗎？」：
  3. (C)老師問我們：今天的作業寫完了嗎？「」
  4. (D)老師問我們，「今天的作業寫完了嗎」？
答案：(A)
解析：引述說話內容要用「冒號＋引號」，問號放在下引號的裡面。
9請用「不但……而且……」造一個完整的句子。
答案：參考答案：他不但主動整理教室，而且還幫同學搬桌椅。
解析：「不但……而且……」是遞進關係，後面那件事的程度要比前面更進一層。
閱讀測驗（第 10～11 題）
　　學校頂樓有一座小小的菜園，是四年級同學一起整理出來的。剛開始土是硬的，大家輪流鬆土、播種、澆水，還做了一張輪值表貼在牆上。
　　有一天午休，突然下起大雨。阿修想起菜苗才剛長出來，二話不說衝上頂樓，把塑膠布蓋在菜圃上，自己淋得全身溼透。
　　後來收成那天，每個人分到一小把青江菜。老師說：「這把菜看起來很普通，可是它是你們自己種出來的。」那天中午的湯，大家都喝得特別乾淨。
10阿修在午休時衝上頂樓，是為了做什麼？
  1. (A)去採收青江菜
  2. (B)把塑膠布蓋在菜圃上避雨
  3. (C)去貼輪值表
  4. (D)去澆水
答案：(B)
解析：第二段寫「把塑膠布蓋在菜圃上，自己淋得全身溼透」，是為了保護剛長出的菜苗。
11「那天中午的湯，大家都喝得特別乾淨。」這句話最主要想表達什麼？
  1. (A)那天的湯特別好喝
  2. (B)因為是自己種的，大家格外珍惜
  3. (C)大家那天特別餓
  4. (D)湯只有一點點
答案：(B)
解析：對照老師說的「它是你們自己種出來的」，可知大家珍惜的是自己付出的成果。

1下列「」中的字，注音正確的是哪一個？
  1. (A)「彷」彿 ㄈㄤˇ
  2. (B)「調」查 ㄊㄧㄠˊ
  3. (C)「露」水 ㄌㄡˋ
  4. (D)「參」差 ㄘㄢ
答案：(A)
解析：彷彿讀ㄈㄤˇ ㄈㄨˊ。調查的調讀ㄉㄧㄠˋ、露水的露讀ㄌㄨˋ、參差的參讀ㄘㄣ，這三個都是常見的破音字。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)絡繹不絕
  2. (B)川流不習
  3. (C)五花八們
  4. (D)名列前矛
答案：(A)
解析：川流不習→川流不息；五花八們→五花八門；名列前矛→名列前茅。
3請把注音寫成國字：溪水ㄑㄧㄥ　ㄔㄜˋ（　　）見底，岸邊的野花ㄕㄥ　ㄎㄞ（　　）。
答案：清澈、盛開
解析：「清澈」的澈是水部；「盛開」的盛在此讀ㄕㄥˋ，指茂盛、繁盛。
4下列哪一句屬於視覺摹寫？
  1. (A)夕陽把海面染成一片金黃。
  2. (B)溪水淙淙，像有人在彈琴。
  3. (C)空氣裡飄著淡淡的花香。
  4. (D)風吹在臉上涼涼的。
答案：(A)
解析：摹寫依感官分類，寫顏色、形狀屬於視覺；第二句聽覺、第三句嗅覺、第四句觸覺。
5「這座山雄偉壯麗，令人（　　）。」括號中填入哪一個詞語最恰當？
  1. (A)嘆為觀止
  2. (B)不知所措
  3. (C)手忙腳亂
  4. (D)無精打采
答案：(A)
解析：嘆為觀止是讚嘆到極點，最適合形容看到壯麗景色的感受。
6請填入合適的關聯詞語：（　　　）天氣不好，我們（　　　）如期出發。
答案：雖然、還是（或：儘管、仍然）
解析：前後意思相反（天氣不好卻仍出發），要用轉折的關聯詞。
7下列各組詞語，意思相近的是哪一組？
  1. (A)美麗－漂亮
  2. (B)炎熱－寒冷
  3. (C)仔細－馬虎
  4. (D)進步－退步
答案：(A)
解析：美麗和漂亮意思相近；其餘三組都是意思相反的詞。
8下列句子中，用詞不恰當的是哪一句？
  1. (A)這篇文章寫得很生動，讀起來津津有味。
  2. (B)他跑得很快，簡直像一陣風。
  3. (C)妹妹考了滿分，難過得手舞足蹈。
  4. (D)秋天的楓葉紅得像火。
答案：(C)
解析：「手舞足蹈」形容非常高興，前面卻用「難過」，語意矛盾，應改成「高興得手舞足蹈」。
9照樣寫句子：夕陽把海面染成一片金黃。→ 秋風把稻田＿＿＿＿＿＿＿＿＿。
答案：參考答案：秋風把稻田吹成一片金黃的波浪。
解析：要用「把……＋動詞＋結果」的句型，後面補上具體的樣子，句子才完整。
閱讀測驗（第 10～11 題）
　　黑冠麻鷺是一種常在校園草地上出現的鳥。牠站著不動的時候，羽毛的顏色和落葉很像，所以常常有人走到牠旁邊才發現。
　　牠最愛吃蚯蚓。捕食的時候會先低下頭，用細長的嘴慢慢靠近，等蚯蚓探出頭來，再一口咬住。因為動作又慢又專注，同學都叫牠「大笨鳥」。
　　其實牠一點也不笨。慢，是為了不驚動獵物；不動，是為了不被看見。
10為什麼黑冠麻鷺常常走到旁邊才被發現？
  1. (A)因為牠飛得很快
  2. (B)因為牠羽毛的顏色和落葉很像
  3. (C)因為牠很小隻
  4. (D)因為牠住在樹上
答案：(B)
解析：第一段說牠站著不動時「羽毛的顏色和落葉很像」，這是保護色的作用。
11最後一段「慢，是為了不驚動獵物；不動，是為了不被看見。」作者想表達什麼？
  1. (A)牠的慢其實是聰明的生存方式
  2. (B)牠真的很笨
  3. (C)牠不喜歡動
  4. (D)牠生病了
答案：(A)
解析：作者先寫同學叫牠大笨鳥，再翻轉說明「慢」與「不動」都有目的，是牠的生存策略。

對應單元第一～四課；人物與敘事類課文（字音字形、成語、句型變換、標點、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，讀音兩個相同的是哪一組？
  1. (A)「好」人／「好」朋友
  2. (B)「重」新／「重」量
  3. (C)「長」大／很「長」
  4. (D)「樂」園／音「樂」
答案：(A)
解析：好人、好朋友的「好」都讀ㄏㄠˇ。重新讀ㄔㄨㄥˊ、重量讀ㄓㄨㄥˋ；長大讀ㄓㄤˇ、很長讀ㄔㄤˊ；樂園讀ㄌㄜˋ、音樂讀ㄩㄝˋ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)迫不及待
  2. (B)興高彩烈
  3. (C)按步就班
  4. (D)心滿易足
答案：(A)
解析：興高彩烈→興高采烈；按步就班→按部就班；心滿易足→心滿意足。
