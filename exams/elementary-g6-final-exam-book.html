編輯說明

一、這本書是什麼。 這是期末考（第三次段考）的合訂題本，不是單張考卷。全書把國語、數學、自然、社會、英語五科放進同一本，每一科底下再依 康軒、南一、翰林、何嘉仁 分節出題，讓同一間安親班裡使用不同版本的孩子，可以各自翻到自己的那一節作答，老師只要備一本書。

二、題目從哪裡來。 全書題目 100% 自編，沒有抄錄任何學校的段考原卷。我們以「中小學題庫網（tcool.cc）」上北、中、南共 9 所國小的段考卷紀錄，來確認 各年級各科目實際採用的版本、段考次數與命題範圍，再依照這個範圍與十二年國教課綱自行命題，避免版權問題。各校版本對照見下一頁。

三、怎麼使用。 螢幕上點每一題下方的「解析」可展開答案與說明；按上方「列印 / 存成 PDF」時，解析會自動隱藏，印出來就是乾淨的作答題本，答案統一收在書末「解答本」。列印請用 Chrome 或 Edge，頁碼才會出現在頁尾。

四、進度提醒。 六上期末考的範圍以第九課之後與後段單元為主：數學為「柱體體積與表面積、速率與統計圖表」，自然為「電磁作用與生物和環境」，社會為「全球關聯與媒體識讀」，英語為「綜合複習與閱讀」。部分學校期末會加考全冊，本冊在解析中也會回顧前面單元的關鍵觀念，可搭配第一、二次段考題本一起複習。

1下列「」中的字，注音正確的是哪一個？
  1. (A)「屏」障 ㄆㄧㄥˊ
  2. (B)「傳」記 ㄔㄨㄢˊ
  3. (C)「差」勁 ㄔㄚ
  4. (D)「著」眼 ㄓㄠˊ
答案：(A)
解析：屏障讀ㄆㄧㄥˊ ㄓㄤˋ。傳記的傳讀ㄓㄨㄢˋ、差勁的差讀ㄔㄚˋ、著眼的著讀ㄓㄨㄛˊ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)相輔相成
  2. (B)相輔相承
  3. (C)相付相成
  4. (D)相輔相城
答案：(A)
解析：「相輔相成」指互相配合、互相促成；成是完成的成。
3請把注音寫成國字：面對不同意見，他總能ㄅㄠ　ㄖㄨㄥˊ（　　）不同的想法，並ㄌㄧˇ　ㄒㄧㄥˋ（　　）地討論。
答案：包容、理性
解析：「包容」的容是宀部；「理性」相對於感性，指依道理判斷。
4「知識像一把鑰匙，能打開世界的門。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)映襯
答案：(A)
解析：有喻體（知識）、喻詞（像）與喻依（鑰匙），是典型的譬喻。
5下列哪一句有語病？
  1. (A)為了避免不再重蹈覆轍，我們檢討了流程。
  2. (B)為了避免重蹈覆轍，我們檢討了流程。
  3. (C)我們檢討流程，以免重蹈覆轍。
  4. (D)我們檢討流程，避免同樣的錯誤再發生。
答案：(A)
解析：「避免」與「不再」都含否定，疊用後意思相反。
6「他總是（　　），從不因為別人的稱讚而自滿。」括號中填入哪一個成語最恰當？
  1. (A)虛懷若谷
  2. (B)自命不凡
  3. (C)目中無人
  4. (D)妄自尊大
答案：(A)
解析：虛懷若谷形容心胸寬大、非常謙虛，與「不自滿」相合。
7請填入合適的關聯詞語：（　　　）資訊來源不明，我們（　　　）不應該任意轉傳。
答案：既然、就（或：因為、所以）
解析：前句提出既定事實，後句推出應有的行為。
8下列各組詞語，意思相反的是哪一組？
  1. (A)理性－感性
  2. (B)理性－冷靜
  3. (C)包容－接納
  4. (D)謙虛－虛心
答案：(A)
解析：理性與感性相對；其餘三組都是近義詞。

閱讀測驗（第 10～11 題）
　　一則影片在網路上瘋傳：某地淹水，畫面裡水已經淹到二樓。留言區湧入大量憤怒與轉發。
　　兩天後，事實查核平台指出，那段影片其實拍攝於三年前的另一個國家。原始畫面沒有變，變的是被放上的說明文字。
　　查核報告的閱讀數，只有原影片的三十分之一。
　　資訊時代最難的，或許不是取得資訊，而是願意多花三十秒去確認。
10那段影片為什麼造成誤解？
  1. (A)影片是舊的、拍攝地也不同，卻被配上錯誤的說明文字
  2. (B)影片是假造的動畫
  3. (C)影片畫質太差
  4. (D)影片沒有聲音
答案：(A)
解析：第二段說明：原始畫面沒有變，變的是被放上的說明文字，且拍攝時間地點都不同。
11作者提到「查核報告的閱讀數只有原影片的三十分之一」，用意是什麼？
  1. (A)說明錯誤訊息傳播得快，更正卻少有人看
  2. (B)說明查核報告寫得不好
  3. (C)說明大家都很忙
  4. (D)說明影片比較好看
答案：(A)
解析：用數字對比凸顯「假訊息跑得比更正快」的現象，帶出最後一段的呼籲。

閱讀測驗（第 10～11 題）
　　海洋裡的塑膠微粒，多半不是一開始就那麼小。大塊的塑膠在陽光與海浪的作用下逐漸碎裂，最後小到肉眼看不見，卻被浮游生物吃下。
　　浮游生物被小魚吃、小魚被大魚吃，最後可能回到人類的餐桌。這條路徑上，塑膠並沒有消失，只是換了位置。
　　所以「丟掉」從來不是真正的結束，只是把問題交給了下一個環節。
10塑膠微粒是怎麼形成的？
  1. (A)大塊塑膠在陽光與海浪作用下逐漸碎裂
  2. (B)工廠直接製造出來的
  3. (C)海水凝結而成
  4. (D)魚類分泌出來的
答案：(A)
解析：第一段說明大塊塑膠受陽光與海浪作用碎裂成極小的顆粒。
11「丟掉從來不是真正的結束，只是把問題交給了下一個環節。」這句話想表達什麼？
  1. (A)廢棄物並不會消失，最終仍會影響環境與人類

  3. (C)塑膠可以自然分解
  4. (D)丟垃圾是好習慣
答案：(A)
解析：呼應前段食物鏈的描述，強調廢棄物只是換了位置而非消失。
