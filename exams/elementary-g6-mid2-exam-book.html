康軒版1-1　國語（康軒版）第二次段考
對應單元第五～八課；議論與傳記類課文（破音字、成語、修辭、語病、長文閱讀）　配分選擇每題 7 分、填充每格 5 分、寫作題 12 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「說」服 ㄕㄨㄟˋ
  2. (B)「模」範 ㄇㄨˊ
  3. (C)「載」重 ㄗㄞˇ
  4. (D)「稱」職 ㄔㄥ
答案：(A)
解析：說服讀ㄕㄨㄟˋ ㄈㄨˊ。模範的模讀ㄇㄛˊ、載重的載讀ㄗㄞˋ、稱職的稱讀ㄔㄥˋ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)集思廣益
  2. (B)集思廣義
  3. (C)集私廣益
  4. (D)積思廣益
答案：(A)
解析：「集思廣益」指集合眾人的想法以獲得更多助益，益是好處。
3請把注音寫成國字：面對批評，他選擇ㄎㄜˋ　ㄍㄨㄢ（　　）檢視，而不是急著ㄅㄧㄢˋ　ㄐㄧㄝˇ（　　）。
答案：客觀、辯解
解析：「客觀」相對於主觀；「辯解」的辯是言部（用言語說明），不要寫成「辨」。
4「他的沉默，比任何一句反駁都更有力量。」這句話使用了什麼修辭？
  1. (A)映襯
  2. (B)設問
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：把「沉默」與「反駁」這兩種相對的情況並列比較，凸顯效果，屬於映襯（對比）。
5下列哪一句有語病？
  1. (A)為了防止這種錯誤不再發生，我們加強了檢查。
  2. (B)為了防止這種錯誤發生，我們加強了檢查。
  3. (C)我們加強檢查，以免這種錯誤再度發生。
  4. (D)我們加強檢查，避免同樣的錯誤發生。
答案：(A)
解析：「防止」本身已含否定，再加「不再」變成雙重否定，意思剛好相反。
6「這項發明（　　），改變了許多人的生活。」括號中填入哪一個成語最恰當？
  1. (A)影響深遠
  2. (B)曇花一現
  3. (C)無關痛癢
  4. (D)微不足道
答案：(A)
解析：後句說「改變了許多人的生活」，前面要填程度相符的「影響深遠」。
7請填入合適的關聯詞語：（　　　）證據不足，我們（　　　）不能任意下結論。
答案：既然、就（或：因為、所以）
解析：前句提出既定事實，後句推出應有的態度，可用「既然……就……」。
8下列各組詞語，意思相反的是哪一組？
  1. (A)客觀－主觀
  2. (B)批評－評論
  3. (C)理性－理智
  4. (D)謙虛－虛心
答案：(A)
解析：客觀與主觀相反；其餘三組都是意思相近的詞。
9請把下面的句子改寫成主動句：　這個問題被大家熱烈地討論著。
答案：參考答案：大家熱烈地討論著這個問題。
解析：被動改主動要把動作者（大家）放到句首當主語，意思不變。
閱讀測驗（第 10～11 題）
　　有人主張，小學生就應該學習寫程式；也有人認為，這個年紀更該多讀書、多跑步。
　　支持者說，程式是未來的語言，愈早接觸愈容易上手。反對者則回應：真正稀缺的不是技術，而是把問題想清楚的能力；技術會過時，思考不會。
　　也許問題從來不是「該不該學」，而是「為什麼學」。如果只是為了不落人後，那麼再新的技能，也只是換一種形式的焦慮。
10反對者認為，比學程式更重要的是什麼？
  1. (A)把問題想清楚的思考能力
  2. (B)背更多單字
  3. (C)學會更多程式語言
  4. (D)提早準備考試
答案：(A)
解析：第二段寫「真正稀缺的不是技術，而是把問題想清楚的能力」。
11作者最後提出的看法是什麼？
  1. (A)重點在於學習的動機，而不只是學不學
  2. (B)應該完全禁止小學生學程式
  3. (C)所有小學生都必須學程式
  4. (D)學習新技能一定會帶來焦慮
答案：(A)
解析：末段把問題從「該不該學」轉到「為什麼學」，並提醒為了不落人後而學只是換一種焦慮。

1下列「」中的字，注音正確的是哪一個？
  1. (A)「熾」熱 ㄔˋ
  2. (B)「湮」滅 ㄧㄡ
  3. (C)「剝」削 ㄅㄠ
  4. (D)「間」歇 ㄐㄧㄢ
答案：(A)
解析：熾熱讀ㄔˋ。湮滅讀ㄧㄢ、剝削讀ㄅㄛ ㄒㄩㄝˋ、間歇讀ㄐㄧㄢˋ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)息息相關
  2. (B)習習相關
  3. (C)息息相觀
  4. (D)悉悉相關
答案：(A)
解析：「息息相關」的息是呼吸，形容關係非常密切，一呼一吸都相連。
3請把注音寫成國字：氣候變遷與每個人的生活ㄒㄧˊ　ㄒㄧˊ（　　）相關，需要各國ㄒㄧㄝˊ　ㄌㄧˋ（　　）合作。
答案：息息、協力

4「冰川一年比一年後退，像一位逐漸消瘦的老人。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)誇飾
答案：(A)
解析：用「像」把冰川比作消瘦的老人，是譬喻；也帶有擬人的色彩。
5下列哪一句使用了層遞修辭？
  1. (A)一個人改變，一個家庭改變，整個社區也跟著改變。
  2. (B)天空是藍的。
  3. (C)他跑得很快。
  4. (D)窗外下著雨。
答案：(A)

6請填入合適的關聯詞語：（　　　）我們現在不採取行動，（　　　）將來要付出更大的代價。
答案：如果、就（或：要是、便）

7下列句子的標點符號，使用正確的是哪一句？
  1. (A)科學家指出：「未來十年是關鍵。」
  2. (B)科學家指出「未來十年是關鍵。」：
  3. (C)科學家指出：未來十年是關鍵「」
  4. (D)科學家指出，「未來十年是關鍵」。
答案：(A)
解析：引述說話內容先用冒號再用引號，句號放在下引號的裡面。
8「杯水車薪」這個成語，用來形容什麼？
  1. (A)幫助太少，無法解決問題
  2. (B)力量非常強大
  3. (C)做事很有效率
  4. (D)資源非常豐富
答案：(A)
解析：用一杯水去救一車著火的柴，比喻力量太小、無濟於事。
9請把下面的句子縮寫成最精簡但保留主要意思的一句話：　來自世界各地的科學家們，在會議上共同提出了減少碳排放的具體建議。
答案：參考答案：科學家提出了減碳建議。
解析：縮寫保留主語、動詞、賓語，刪去修飾語（來自世界各地、在會議上、共同、具體）。
閱讀測驗（第 10～11 題）
　　一件棉 T 恤，從種棉花到送到你手上，大約要用掉兩千七百公升的水，相當於一個人三年的飲用量。
　　快時尚讓衣服變得便宜，也變得容易被丟棄。有研究指出，一件衣服平均只被穿七到十次就被淘汰。這些被丟掉的衣服，多數並沒有被回收，而是進了掩埋場或被燒掉。
　　把一件衣服多穿一年，可以減少約四分之一的碳足跡。原來，最環保的衣服，往往就是你衣櫃裡已經有的那一件。
10根據本文，一件衣服平均被穿幾次就被淘汰？
  1. (A)七到十次
  2. (B)一百次
  3. (C)三年
  4. (D)二十七次
答案：(A)
解析：第二段明確指出「平均只被穿七到十次就被淘汰」。
11「最環保的衣服，往往就是你衣櫃裡已經有的那一件。」這句話的意思是什麼？
  1. (A)延長既有衣物的使用，比買新的環保衣服更有效
  2. (B)應該買更多標榜環保的衣服
  3. (C)衣櫃裡的衣服都是環保材質
  4. (D)不需要洗衣服
答案：(A)
解析：呼應前一句「多穿一年可減少約四分之一碳足跡」，強調減量與延長使用才是根本。
