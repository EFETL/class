1下列「」中的字，注音正確的是哪一個？
  1. (A)「屏」息 ㄅㄧㄥˇ
  2. (B)「乘」機 ㄔㄥˋ
  3. (C)「著」手 ㄓㄠˊ
  4. (D)「處」置 ㄔㄨˋ
答案：(A)
解析：屏息（憋住呼吸）讀ㄅㄧㄥˇ。乘機讀ㄔㄥˊ、著手讀ㄓㄨㄛˊ、處置讀ㄔㄨˇ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)融會貫通
  2. (B)融會灌通
  3. (C)溶會貫通
  4. (D)融匯貫通
答案：(A)
解析：「融會貫通」的會是融合理解、貫是貫穿，不能寫成「灌」或「匯」。
3請把注音寫成國字：他的解說ㄕㄥ　ㄉㄨㄥˋ（　　）有趣，讓抽象的道理變得ㄑㄧㄥ　ㄒㄧ（　　）易懂。
答案：生動、清晰
解析：「生動」指有活力、不呆板；「清晰」的晰是日部，指清楚分明。
4「他的話像一盆冷水，澆熄了大家的熱情。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：用「像」把話比作冷水，是譬喻；「澆熄熱情」則把抽象的情緒具體化。
5下列哪一句使用了排比？
  1. (A)讀書要專心，做事要用心，待人要真心。
  2. (B)他跑得比風還快。
  3. (C)難道我們就這樣算了嗎？
  4. (D)窗外傳來一陣蟬鳴。
答案：(A)
解析：排比是三個以上結構相似的句子並列，用來加強語氣與節奏。
6「他做事一向（　　），從不因為困難就退縮。」括號中填入哪一個成語最恰當？
  1. (A)鍥而不捨
  2. (B)半途而廢
  3. (C)虎頭蛇尾
  4. (D)一曝十寒
答案：(A)
解析：鍥而不捨形容有毅力、堅持到底，與「從不退縮」相合；其餘三個都是缺乏恆心。
7請填入合適的關聯詞語：（　　　）努力練習，（　　　）能在關鍵時刻穩住表現。
答案：只有、才（或：唯有、才）
解析：「只有……才……」表示必要條件：沒有前者就不會有後者。
8下列哪一句有語病？
  1. (A)他大約十二歲左右。
  2. (B)他大約十二歲。
  3. (C)他今年十二歲。
  4. (D)他快滿十二歲了。
答案：(A)
解析：「大約」和「左右」意思重複，只留一個即可。
9請把下面的句子改寫成不改變原意的另一種說法：　沒有一個人不佩服他的毅力。
答案：參考答案：每個人都佩服他的毅力。
解析：「沒有一個人不……」是雙重否定，等於全部肯定，改寫時要把語氣拉平但意思不變。

　　城市裡有一座老市場，屋頂會漏水，攤位也窄。市府提出改建計畫，攤商卻分成兩派：有人希望環境更好，有人擔心改建期間沒有收入。
　　後來市府辦了三場說明會，把工程分成兩期，讓攤商輪流搬到臨時攤位，改建期間也減收租金。雖然過程仍有爭執，但至少每個人的擔心都被說出來、被回應。
　　落成那天，一位賣菜的阿姨說：「重要的不是新市場多漂亮，是我們一起把話講開了。」
10攤商為什麼會分成兩派？
  1. (A)有人希望環境改善，有人擔心改建期間失去收入
  2. (B)有人想搬家，有人不想
  3. (C)有人喜歡漏水的屋頂
  4. (D)有人不想繳租金
答案：(A)
解析：第一段直接寫出兩派的立場：期待更好的環境 vs 擔心沒有收入。
11從市府的做法可以看出，解決公共爭議時最重要的是什麼？
  1. (A)充分溝通，並設法照顧不同立場的需要

  3. (C)直接強制執行
  4. (D)放棄不做
答案：(A)
解析：市府辦說明會、分期施工、減收租金，都是回應不同需求的具體作為，最後阿姨的話也點出溝通的價值。

閱讀測驗（第 10～11 題）
　　臺灣的中央山脈像一道屏障，把來自海洋的水氣攔住。水氣被迫抬升、凝結，於是山區降下大量的雨。這些雨水滲進地底、匯成溪流，再流向平原。
　　我們每天打開水龍頭用的水，很可能就來自幾十公里外的一座山。森林裡的落葉與樹根像海綿一樣把水留住，慢慢釋放，讓溪流在不下雨的日子也不會乾涸。
　　所以保護山林，其實也是在保護自己的水杯。
10根據本文，山區為什麼會降下大量的雨？
  1. (A)水氣被山脈攔住後抬升凝結
  2. (B)山上的樹木會製造雨水
  3. (C)山上的氣溫特別高
  4. (D)山上的風特別小
答案：(A)
解析：第一段說明中央山脈攔住海洋來的水氣，水氣被迫抬升、凝結而降雨（地形雨）。
11作者把森林裡的落葉與樹根比喻成「海綿」，是要說明什麼？
  1. (A)森林能吸收並慢慢釋放水分，穩定溪流
  2. (B)森林很柔軟可以躺
  3. (C)落葉可以拿來洗東西
  4. (D)樹根會把水全部吸乾
答案：(A)
解析：海綿吸水後會慢慢釋出，比喻森林涵養水源的功能，使溪流不易乾涸。
