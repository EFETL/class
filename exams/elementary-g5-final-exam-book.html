編輯說明

一、這本書是什麼。 這是期末考（第三次段考）的合訂題本，不是單張考卷。全書把國語、數學、自然、社會、英語五科放進同一本，每一科底下再依 康軒、南一、翰林、何嘉仁 分節出題，讓同一間安親班裡使用不同版本的孩子，可以各自翻到自己的那一節作答，老師只要備一本書。

二、題目從哪裡來。 全書題目 100% 自編，沒有抄錄任何學校的段考原卷。我們以「中小學題庫網（tcool.cc）」上北、中、南共 9 所國小的段考卷紀錄，來確認 各年級各科目實際採用的版本、段考次數與命題範圍，再依照這個範圍與十二年國教課綱自行命題，避免版權問題。各校版本對照見下一頁。

三、怎麼使用。 螢幕上點每一題下方的「解析」可展開答案與說明；按上方「列印 / 存成 PDF」時，解析會自動隱藏，印出來就是乾淨的作答題本，答案統一收在書末「解答本」。列印請用 Chrome 或 Edge，頁碼才會出現在頁尾。

四、進度提醒。 五上期末考的範圍以第九課之後與後段單元為主：數學為「線對稱、體積與容積、小數乘法與折線圖」，自然為「水溶液與熱」，社會為「臺灣的人口與交通產業」，英語為「情境會話與綜合複習」。部分學校期末會加考全冊，本冊在解析中也會回顧前面單元的關鍵觀念，可搭配第一、二次段考題本一起複習。

五、配分建議。 每一節可獨立當成一份小考（滿分 100 分）；若要組成一份完整段考卷，建議：國語 30 分＋數學 30 分＋自然 20 分＋社會 20 分，英語另外單獨計分。

康軒版1-1　國語（康軒版）期末考
對應單元第九～十四課（含全冊複習）：破音字、成語、修辭、語病、長文閱讀　配分選擇每題 7 分、填充每格 5 分、寫作題 12 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「琢」磨 ㄓㄨㄛˊ
  2. (B)「奔」馳 ㄅㄣˋ
  3. (C)「勉」強 ㄑㄧㄤˊ
  4. (D)「載」重 ㄗㄞˇ
答案：(A)
解析：琢磨讀ㄓㄨㄛˊ ㄇㄛˊ。奔馳的奔讀ㄅㄣ（一聲）、勉強的強讀ㄑㄧㄤˇ、載重的載讀ㄗㄞˋ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)水落石出
  2. (B)水落石初
  3. (C)水絡石出
  4. (D)水落實出
答案：(A)
解析：「水落石出」比喻真相完全顯露；石頭在水退後露出來。
3請把注音寫成國字：他一再ㄊㄨㄟ　ㄑㄧㄠ（　　）文字，只為了把想法表達得更ㄐㄧㄥ　ㄓㄨㄣˇ（　　）。
答案：推敲、精準
解析：「推敲」典出賈島反覆斟酌「推」與「敲」；「精準」的準是水部。
4「歲月像一條無聲的河，帶走了很多東西。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：有喻體（歲月）、喻詞（像）與喻依（河），是典型的譬喻。
5下列哪一句有語病？
  1. (A)他幾乎快要完成了作品。
  2. (B)他快要完成作品了。
  3. (C)他即將完成作品。
  4. (D)他就要把作品完成了。
答案：(A)
解析：「幾乎」和「快要」意思重複，留一個即可。
6「他做事總是（　　），連小地方都不放過。」括號中填入哪一個成語最恰當？
  1. (A)鉅細靡遺
  2. (B)粗心大意
  3. (C)敷衍了事
  4. (D)得過且過
答案：(A)
解析：鉅細靡遺是大小事都不遺漏，與「連小地方都不放過」相合。
7請填入合適的關聯詞語：（　　　）遇到再大的困難，他（　　　）不曾放棄。
答案：無論、都（或：不管、也）
解析：「無論……都……」表示在任何條件下結果都一樣。
8下列各組詞語，意思相近的是哪一組？
  1. (A)謙虛－虛心
  2. (B)謙虛－驕傲
  3. (C)勤勞－懶惰
  4. (D)仔細－馬虎
答案：(A)
解析：謙虛與虛心意思相近；其餘三組都是反義詞。
9請把下面的句子改寫成不改變原意的另一種說法：　沒有人不喜歡他的溫柔。
答案：參考答案：每個人都喜歡他的溫柔。
解析：「沒有人不……」是雙重否定，等於全部肯定。
閱讀測驗（第 10～11 題）
　　城市圖書館的角落，有一區「還書後的第二次機會」書架，放的都是被歸還後暫時無人借閱的書。
　　館員發現，只要把書從書庫搬到這個顯眼的架子上，同一本書的借閱率就會明顯上升。書沒有改變，改變的只是它被看見的機會。
　　也許很多事情也是這樣：不是不夠好，只是還沒被放在對的位置上。
10「還書後的第二次機會」書架，放的是什麼書？
  1. (A)歸還後暫時無人借閱的書
  2. (B)全新出版的書
  3. (C)破損待修的書
  4. (D)館員推薦的暢銷書
答案：(A)
解析：第一段明確說明是「被歸還後暫時無人借閱的書」。
11最後一段「不是不夠好，只是還沒被放在對的位置上」，最主要想表達什麼？
  1. (A)適當的機會與位置，能讓原本被忽略的價值被看見
  2. (B)那些書其實很糟
  3. (C)位置一點也不重要
  4. (D)圖書館應該少買書
答案：(A)
解析：呼應前段「書沒有改變，改變的只是它被看見的機會」，強調機會與環境的重要。

閱讀測驗（第 10～11 題）
　　一片森林被砍掉之後，最先消失的不是樹，而是聲音。鳥鳴、蟲叫、風穿過樹葉的沙沙聲，全都不見了。
　　有研究團隊在復育造林的區域架設錄音機，長期記錄聲音的變化。三年後，他們從錄音中聽見鳥種一點一點回來——聲音成了森林是否真正恢復的指標。
　　原來，健康的森林不只看得見，也聽得見。
10研究團隊用什麼方式判斷森林是否恢復？
  1. (A)長期錄音，記錄聲音（鳥種）的變化
  2. (B)數樹木的數量
  3. (C)測量土壤的顏色
  4. (D)看照片
答案：(A)
解析：第二段寫他們架設錄音機長期記錄，並從錄音中聽見鳥種回來。
11「健康的森林不只看得見，也聽得見。」這句話的意思是什麼？
  1. (A)除了樹木的外觀，聲音的豐富度也能反映生態的健康
  2. (B)森林會說話
  3. (C)只要聽得到聲音就是好森林
  4. (D)看不見的森林才健康
答案：(A)
解析：呼應前段「聲音成了森林是否真正恢復的指標」，說明生態健康有多重判斷方式。
