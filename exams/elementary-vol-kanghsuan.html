國語／數學／自然／社會／英語　共 51 題
本章是 康軒版三年級上學期第一次段考的全科練習，每一節（國語／數學／自然／社會／英語）都可以單獨當成一份小考使用。各節開頭都標示了對應單元，若貴班進度不同，直接略過該節即可。
國語1-1　國語　三年級上學期 第一次段考
對應單元第一～四課；主題多為校園生活與自然觀察（字詞、量詞、標點、擬人修辭、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)微風輕「拂」ㄈㄨˊ
  2. (B)一片「稻」田 ㄊㄠˊ
  3. (C)「攤」開地圖 ㄊㄢˇ
  4. (D)一「盞」小燈 ㄓㄢˋ
答案：(A)
解析：拂讀ㄈㄨˊ，正確。稻讀ㄉㄠˋ、攤讀ㄊㄢ（一聲）、盞讀ㄓㄢˇ（三聲），其餘三個都標錯了。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)完成心愿
  2. (B)迫不急待
  3. (C)興高采烈
  4. (D)專心至志
答案：(C)
解析：「興高采烈」正確。心愿→心願；迫不急待→迫不及待（來不及等待）；專心至志→專心致志（致，把心力用到某處）。
3請把注音寫成國字：小明ㄗˇ　ㄒㄧˋ（　　）地ㄍㄨㄢ　ㄔㄚˊ（　　）葉子的形狀，還畫下來做紀錄。
答案：仔細、觀察
解析：ㄗˇㄒㄧˋ是「仔細」（仔的部首是人部）；ㄍㄨㄢㄔㄚˊ是「觀察」，注意「察」是宀部，不要寫成「查」。
4下列量詞使用正確的是哪一個？
  1. (A)一「畝」稻田
  2. (B)一「棵」小鳥
  3. (C)一「條」教室
  4. (D)一「片」故事書
答案：(A)
解析：田地用「畝」。小鳥用「隻」、教室用「間」、故事書用「本」。
5「聞」這個字的部首是什麼？
  1. (A)門
  2. (B)耳
  3. (C)日
  4. (D)口
答案：(B)
解析：「聞」是用耳朵聽，部首取「耳」，門只是外框（聲符）。查字典時要先找耳部，再數 8 畫。
6「上課鐘響了，同學們（　　）地回到座位上。」括號中填入哪一個詞語最恰當？
  1. (A)井然有序
  2. (B)七手八腳
  3. (C)無精打采
  4. (D)自言自語
答案：(A)
解析：井然有序＝很整齊、有秩序，最符合聽到鐘聲回座位的情形。七手八腳是慌亂、無精打采是沒有精神、自言自語是自己對自己說話，都不合句意。
7請為這個句子加上正確的標點符號（寫出完整句子）：　媽媽問我　今天在學校過得好嗎
答案：媽媽問我：「今天在學校過得好嗎？」
解析：說話的內容要先用冒號（：）再用引號（「」）框起來；句子在問人，所以引號裡用問號（？），問號要放在下引號的裡面。
8「小草在風中向我們招手。」這句話使用了什麼修辭法？
  1. (A)譬喻
  2. (B)擬人
  3. (C)誇飾
  4. (D)排比
答案：(B)
解析：「招手」是人的動作，作者把小草當成人來寫，所以是擬人。譬喻要有「像、好像、彷彿」等喻詞。
9請用「一邊……一邊……」造一個完整的句子。
答案：參考答案：妹妹一邊哼著歌，一邊幫忙擦桌子。
解析：「一邊……一邊……」用來表示兩件事同時進行，前後要各接一個動作，句末別忘了加句號。
閱讀測驗（第 9～10 題）
　　學校中庭有一棵老榕樹，它的鬍鬚長長地垂下來，像一位慈祥的老公公。下課鐘一響，我們就跑到樹下玩。有人在樹蔭裡看書，有人蹲著看螞蟻搬東西。
　　有一天，我發現榕樹的葉子上有一個小小的洞，仔細一看，原來是毛毛蟲把葉子當成午餐了。老師說：「這也是大自然的一部分喔！」從那天起，我每天下課都會去看看那隻毛毛蟲，看牠什麼時候會變成蝴蝶。
10短文中把老榕樹比喻成什麼？
  1. (A)一位慈祥的老公公
  2. (B)一把大雨傘
  3. (C)一隻毛毛蟲
  4. (D)一座小山
答案：(A)
解析：第一段寫「它的鬍鬚長長地垂下來，像一位慈祥的老公公」，有喻詞「像」，是譬喻修辭。
11根據短文，葉子上的小洞是怎麼來的？
  1. (A)被風吹破的
  2. (B)毛毛蟲吃出來的
  3. (C)同學不小心弄破的
  4. (D)太陽晒出來的
答案：(B)

  1. (A)5990
  2. (B)6010
  3. (C)5909
  4. (D)6001
答案：(B)
解析：先比千位：6010 和 6001 都是 6，比 5 開頭的大；再比百位，6010 是 0、6001 也是 0；比十位，1 大於 0，所以 6010 最大。

1植物用來固定身體、並吸收水分和養分的部位是什麼？
  1. (A)根
  2. (B)莖
  3. (C)葉
  4. (D)花
答案：(A)
解析：根長在土裡，一方面把植物固定住不被風吹倒，一方面吸收水分和溶在水裡的養分。
2使用放大鏡觀察小花小葉時，下列哪一個做法正確？
  1. (A)把放大鏡拿去對著太陽看，比較亮
  2. (B)放大鏡靠近眼睛，再移動要看的東西對焦
  3. (C)用放大鏡壓在葉子上用力壓平
  4. (D)放大鏡離眼睛愈遠看得愈清楚
答案：(B)
解析：正確用法是把放大鏡靠近眼睛，前後移動觀察物（或身體）直到看清楚。絕對不可以用放大鏡看太陽，會傷害眼睛。
3一片完整的葉子，可以分成葉身（葉片）、＿＿＿＿＿和葉脈三個部分。
答案：葉柄
解析：葉柄是連接葉身和莖的部分，水分和養分要經過葉柄進出葉子。
4我們平常吃的馬鈴薯，是植物的哪一個部位？
  1. (A)根
  2. (B)莖
  3. (C)葉
  4. (D)果實
答案：(B)

5下列哪一種植物的葉脈是平行脈？
  1. (A)榕樹葉
  2. (B)玉米葉
  3. (C)楓葉
  4. (D)絲瓜葉
答案：(B)
解析：玉米、竹子、水稻的葉脈像線一樣平行排列，叫平行脈；榕樹、楓葉、絲瓜的葉脈交錯成網狀，叫網狀脈。
6做校園植物觀察紀錄時，除了畫圖和描述外，至少還要寫下觀察的＿＿＿＿＿和＿＿＿＿＿。
答案：日期（時間）、地點
解析：科學紀錄要能被別人重複驗證，所以日期、地點（也可以加上天氣）都要寫清楚，之後才能比較植物的變化。
7植物產生種子的順序，下列哪一個正確？
  1. (A)種子→花→果實
  2. (B)花→果實→種子
  3. (C)果實→花→種子
  4. (D)葉→花→種子
答案：(B)
解析：花授粉後會結成果實，種子包在果實裡面，所以順序是花→果實→種子。
8如果把一株小植物的葉子全部剪掉，最可能發生什麼事？
  1. (A)長得更快，因為不用養葉子
  2. (B)因為無法製造養分，慢慢枯萎
  3. (C)立刻開花結果
  4. (D)變得比較不怕蟲咬
答案：(B)
解析：葉子是植物製造養分的地方（行光合作用），葉子被剪光就沒辦法製造養分，植物會愈來愈虛弱甚至枯死。
9請寫出植物的任兩個器官，並各說明它的一個功能。
答案：參考答案：根—吸收水分和養分（並固定植物）；葉—製造植物需要的養分。
