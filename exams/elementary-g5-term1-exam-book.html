編輯說明

一、這本書是什麼。 這是一本「合訂題本」，不是單張考卷。全書把國語、數學、自然、社會、英語五科放進同一本，每一科底下再依 康軒、南一、翰林、何嘉仁 分節出題，讓同一間安親班裡使用不同版本的孩子，可以各自翻到自己的那一節作答，老師只要備一本書。

二、題目從哪裡來。 全書題目 100% 自編，沒有抄錄任何學校的段考原卷。我們以「中小學題庫網（tcool.cc）」上北、中、南共 9 所國小的段考卷紀錄，來確認 各年級各科目實際採用的版本、段考次數與命題範圍，再依照這個範圍與十二年國教課綱自行命題，避免版權問題。各校版本對照見下一頁。

三、怎麼使用。 螢幕上點每一題下方的「解析」可展開答案與說明；按上方「列印 / 存成 PDF」時，解析會自動隱藏，印出來就是乾淨的作答題本，答案統一收在書末「解答本」。列印請用 Chrome 或 Edge，頁碼才會出現在頁尾。

四、進度提醒。 各校教學進度不同，第一次段考的實際範圍請以任課老師公布為準。五上第一次段考三家版本的核心範圍相當一致：數學為「因數與倍數、多位小數」，自然為「觀測太陽」，社會為「臺灣的位置與地形氣候」，因此本冊各版本節次的差異主要在題材與敘述方式。

康軒版1-1　國語（康軒版）第一次段考
對應單元第一～四課；記敘與抒情類課文（破音字、成語、譬喻與擬人、關聯詞、長文閱讀）　配分選擇每題 7 分、填充每格 5 分、寫作題 12 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)勉「強」ㄑㄧㄤˇ
  2. (B)「強」調 ㄑㄧㄤˇ
  3. (C)倔「強」ㄑㄧㄤˊ
  4. (D)「強」盜 ㄐㄧㄤˋ
答案：(A)
解析：「強」是三音字：勉強、強迫讀ㄑㄧㄤˇ；強調、強盜讀ㄑㄧㄤˊ；倔強讀ㄐㄧㄤˋ。只有第一個標對。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)一鼓作氣
  2. (B)按耐不住
  3. (C)不徑而走
  4. (D)川流不習
答案：(A)
解析：按耐不住→按捺不住（捺，壓住）；不徑而走→不脛而走（脛，小腿）；川流不習→川流不息（息，停止）。
3請把注音寫成國字：他的態度非常ㄐㄧㄢ　ㄉㄧㄥˋ（　　），準備的資料也十分ㄈㄥ　ㄈㄨˋ（　　）。
答案：堅定、豐富
解析：「堅」上面是「臤」不要寫成「艮」；「豐」的下方是「豆」，不要少寫橫畫。
4「金黃色的稻田，像一張鋪到天邊的地毯。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)轉品
答案：(A)
解析：有喻體（稻田）、喻詞（像）、喻依（地毯），是典型的譬喻（明喻）。
5下列哪一句使用了排比修辭？
  1. (A)春天的雨是溫柔的，夏天的雨是急躁的，秋天的雨是清冷的。
  2. (B)他跑得比風還快。
  3. (C)難道我們就這樣放棄嗎？
  4. (D)窗外傳來一陣陣蟬鳴。
答案：(A)
解析：排比是用三個以上結構相似的句子並列，加強語氣。第二句是誇飾、第三句是設問、第四句只是敘述。
6「他做事總是（　　），從來不半途而廢。」括號中填入哪一個成語最恰當？
  1. (A)持之以恆
  2. (B)三心二意
  3. (C)得過且過
  4. (D)虎頭蛇尾
答案：(A)
解析：後半句說「不半途而廢」，前面要填意思相合的「持之以恆」。其餘三個都是做事不能堅持的意思，語意相反。
7請填入合適的關聯詞語：他（　　　）功課忙，（　　　）每天都抽出時間運動。
答案：雖然、但是（或：儘管、還是）
解析：前後兩句意思相反（功課忙 vs 仍然運動），要用表示轉折的關聯詞。
8下列句子的標點符號，使用正確的是哪一句？
  1. (A)他小聲地說：「我明天再告訴你。」
  2. (B)他小聲地說「我明天再告訴你。」：
  3. (C)他小聲地說，「我明天再告訴你」。
  4. (D)他小聲地說：我明天再告訴你。
答案：(A)
解析：引述說話內容時，先用冒號（：）再用引號（「」），句號放在下引號的裡面。
9請把這個句子加以擴寫（至少加入兩個修飾的詞語）：　小鳥飛過天空。
答案：參考答案：一群羽毛雪白的小鳥，輕快地飛過黃昏時橘紅色的天空。
解析：擴寫是在主語、動詞或賓語前加上修飾語（形容詞、副詞、數量詞），讓畫面更具體，但不能改變原本的意思。
閱讀測驗（第 10～11 題）
　　外公家門前有一口老井。小時候我最喜歡趴在井邊，看水面上晃動的天空。外公說，這口井從他還是孩子的時候就在了，村子裡的人靠它煮飯、洗衣，也靠它度過好幾次乾旱。
　　後來家家戶戶接了自來水，井漸漸沒有人使用，井口長出了青苔。有一年颱風停水三天，鄰居們又提著水桶回到井邊排隊。外公一邊搖著把手一邊笑說：「你看，它一直都在這裡等著呢。」
　　那天我才明白，有些東西即使被冷落，也不會失去它的價值。
10根據本文，村民後來為什麼很少使用那口老井？
  1. (A)井水乾涸了
  2. (B)家家戶戶接了自來水
  3. (C)井被颱風吹壞了
  4. (D)外公不讓人使用
答案：(B)
解析：第二段第一句明確說「後來家家戶戶接了自來水，井漸漸沒有人使用」，其他選項文中都沒有提到。
11外公說「你看，它一直都在這裡等著呢。」這句話最主要想表達什麼？
  1. (A)老井雖然被冷落，需要時仍然有用
  2. (B)老井應該立刻拆掉
  3. (C)自來水比井水乾淨
  4. (D)颱風每年都會來
答案：(A)
解析：對照最後一段「有些東西即使被冷落，也不會失去它的價值」，可知外公是在強調老井的價值一直都在。
南一版1-2　國語（南一版）第一次段考
對應單元第一～四課；寫景與說明類課文（形近字、詞語辨析、摹寫與轉化、句型變換、長文閱讀）　配分選擇每題 7 分、填充每格 5 分、寫作題 12 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「哄」堂大笑 ㄏㄨㄥ
  2. (B)「載」重 ㄗㄞˇ
  3. (C)「差」勁 ㄔㄚ
  4. (D)「數」見不鮮 ㄕㄨˋ
答案：(A)
解析：哄堂大笑讀ㄏㄨㄥ（一聲），指全場一起大笑。載重讀ㄗㄞˋ、差勁讀ㄔㄚˋ、數見不鮮的「數」讀ㄕㄨㄛˋ（屢次的意思），這三個都標錯了。
2下列各組字，字形完全正確的是哪一組？
  1. (A)賞心悅目／變本加厲
  2. (B)賞心悅木／變本加利
  3. (C)賞心悅目／變本加利
  4. (D)賞心悅木／變本加厲
答案：(A)
解析：「賞心悅目」的悅是心情愉快、目是眼睛；「變本加厲」的厲是猛烈的意思，不能寫成「利」。
3請把注音寫成國字：夕陽把海面染成一片ㄘㄢˋ　ㄌㄢˋ（　　）的金黃，令人ㄊㄠˊ　ㄗㄨㄟˋ（　　）。
答案：燦爛、陶醉
解析：「燦爛」兩字都是火部，形容光彩耀眼；「陶醉」的醉是酉部，和酒有關，引申為沉浸在某種情境中。
4「風輕輕地梳理著柳樹的長髮。」這句話使用了什麼修辭？
  1. (A)擬人（轉化）
  2. (B)誇飾
  3. (C)設問
  4. (D)映襯
答案：(A)
解析：把風寫成會「梳理」、把柳枝寫成「長髮」，將物當作人來描寫，是擬人（轉化）。
5下列哪一句屬於聽覺摹寫？
  1. (A)溪水淙淙，像有人在遠處彈琴。
  2. (B)天空藍得發亮。
  3. (C)空氣裡飄著淡淡的桂花香。
  4. (D)冰涼的溪水滑過腳背。
答案：(A)
解析：摹寫依感官分類：聽覺（聲音）、視覺（顏色形狀）、嗅覺（氣味）、觸覺（冷熱軟硬）。第一句寫聲音，屬聽覺摹寫。
6下列句子中，詞語使用不恰當的是哪一句？
  1. (A)他做事一絲不苟，資料總是整理得很仔細。
  2. (B)這座橋巍峨聳立，已經有百年歷史。
  3. (C)弟弟考了滿分，媽媽氣得眉開眼笑。
  4. (D)他的字跡工整，看起來賞心悅目。
答案：(C)
解析：「眉開眼笑」是形容非常高興，前面卻用「氣得」，語意互相矛盾，應改成「高興得眉開眼笑」。
7請填入合適的關聯詞語：（　　　）多用一次塑膠袋，（　　　）多製造一分垃圾。
答案：每、就（或：只要、就）
解析：這是條件關係：前面提出條件，後面說出必然的結果，可用「只要……就……」或「每……就……」。
8「這麼美的風景，怎能不讓人流連忘返呢？」這句話使用了什麼修辭？
  1. (A)設問（激問）
  2. (B)譬喻
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：用問句的形式表達肯定的意思（一定讓人流連忘返），答案就在問題裡，屬於設問中的激問（反問）。
9請把下面的句子改寫成被動句：　颱風吹倒了路旁那棵大樹。
答案：參考答案：路旁那棵大樹被颱風吹倒了。
解析：被動句要把承受動作的人或物放到句首，再用「被」帶出動作者，句意不變。
閱讀測驗（第 10～11 題）
　　黑面琵鷺每年秋天從北方飛來臺灣的曾文溪口過冬，隔年春天再北返繁殖。牠們的嘴又長又扁，像一支黑色的湯匙，覓食時會左右擺動嘴巴在淺水中掃動，把小魚小蝦撈起來。
　　三十多年前，全世界的黑面琵鷺一度只剩下不到三百隻。經過保育人員長期記錄、劃設保護區，加上民眾的協助通報，數量才慢慢回升。牠們願不願意再來，其實是一面鏡子：照出我們對待這片溼地的方式。
10根據本文，黑面琵鷺的覓食方式是什麼？
  1. (A)用長嘴在淺水中左右掃動，撈起小魚小蝦
  2. (B)在空中俯衝抓魚
  3. (C)用腳踩住獵物
  4. (D)啄食樹上的果實
答案：(A)
解析：第一段說「覓食時會左右擺動嘴巴在淺水中掃動，把小魚小蝦撈起來」，這是牠們特有的掃食行為。
11「牠們願不願意再來，其實是一面鏡子」這句話的意思最接近下列哪一項？
  1. (A)黑面琵鷺喜歡照鏡子
  2. (B)溼地環境保護得好不好，會反映在鳥的數量上
  3. (C)鏡子可以吸引候鳥
  4. (D)候鳥的數量和人類無關

對應單元長母音發音規則（a_e、ee／ea）、現在進行式對話、閱讀理解　配分選擇每題 8 分、填充每格 5 分、寫作題 10 分
1下列哪一個單字的 a 發長母音 /eɪ/（像字母 A 的音）？
  1. (A)cake
  2. (B)cat
  3. (C)bag
  4. (D)map
答案：(A)
解析：「子音＋a＋子音＋e」的組合（a_e）中，a 發字母本音 /eɪ/、字尾 e 不發音，例如 cake、name、game。cat、bag、map 則發短母音 /æ/。
2下列哪一組單字的畫線部分發音相同？
  1. (A)see / tea
  2. (B)see / red
  3. (C)tea / bed
  4. (D)red / bee
答案：(A)
解析：ee 和 ea 常常都發長音 /iː/，例如 see、tea、green、eat。red、bed 則是短母音 /e/。
3請依照 a_e 的規則拼出單字：把 cap 中間加上長母音規則後變成 ＿＿＿＿（帽子→斗篷／披風）。
答案：cape
解析：cap /kæp/ 加上字尾 e 變成 cape /keɪp/，中間的 a 由短音變長音，這就是「魔法 e」的作用。
4A: What is he doing?　B: ＿＿＿＿
  1. (A)He is eating an apple.
  2. (B)He eat an apple.
  3. (C)He is eat an apple.
  4. (D)He an apple.
答案：(A)
解析：現在進行式＝be 動詞＋動詞-ing。He 要搭配 is，動詞 eat 要改成 eating。
5下列單字，哪一個的母音不是長音？
  1. (A)make
  2. (B)name
  3. (C)game
  4. (D)hat
答案：(D)
解析：make、name、game 都符合 a_e 的長母音規則；hat 是「子音＋a＋子音」的短母音 /æ/。
6請把句子改成現在進行式：They play soccer. → They ＿＿＿ ＿＿＿＿＿＿ soccer.
答案：are playing
解析：主詞 They 要搭配 are，動詞 play 加 -ing 成 playing（play 字尾是母音＋y，直接加 ing，不用改字）。
