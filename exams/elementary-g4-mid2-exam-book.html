1下列「」中的字，注音正確的是哪一個？
  1. (A)「懇」求 ㄎㄣˇ
  2. (B)「率」領 ㄌㄩˋ
  3. (C)「勉」強 ㄇㄧㄢˋ
  4. (D)「載」歌載舞 ㄗㄞˇ
答案：(A)
解析：懇求讀ㄎㄣˇ。率領的率讀ㄕㄨㄞˋ、勉強的勉讀ㄇㄧㄢˇ、載歌載舞的載讀ㄗㄞˋ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)感激涕零
  2. (B)感激啼零
  3. (C)感激涕伶
  4. (D)感計涕零
答案：(A)
解析：「感激涕零」的涕是眼淚、零是落下，形容非常感動而流淚。
3請把注音寫成國字：面對突如其來的困難，他仍然ㄓㄣˋ　ㄉㄧㄥˋ（　　），一步一步ㄎㄜˋ　ㄈㄨˊ（　　）。
答案：鎮定、克服
解析：「鎮定」的鎮是金部；「克服」的克不要寫成「刻」。
4「他一句話也不說，只是靜靜地聽著。」這句話最能表現他什麼樣的態度？
  1. (A)專注而尊重
  2. (B)不耐煩
  3. (C)很生氣
  4. (D)覺得無聊
答案：(A)
解析：安靜聆聽、不打斷，通常表示專注與對說話者的尊重。
5「時間像沙漏裡的沙，一點一點溜走。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)設問
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：有喻體（時間）、喻詞（像）與喻依（沙），是典型的譬喻。
6「他做事（　　），從不拖延。」括號中填入哪一個成語最恰當？
  1. (A)劍及履及
  2. (B)半途而廢
  3. (C)拖泥帶水
  4. (D)得過且過
答案：(A)
解析：劍及履及形容行動非常迅速；其餘三個都是拖延或不認真的意思，與「從不拖延」矛盾。
7請填入合適的關聯詞語：他（　　　）年紀小，（　　　）想法很成熟。
答案：雖然、但是
解析：前後意思相反（年紀小 vs 想法成熟），要用轉折的關聯詞。
8下列哪一句沒有語病？
  1. (A)這次比賽讓我學到很多。
  2. (B)透過這次比賽，讓我學到很多。
  3. (C)經由這次比賽，使我學到很多。
  4. (D)在這次比賽中，使我學到很多。
答案：(A)
解析：「透過／經由……讓（使）……」會讓句子缺少主語，是常見的語病。
9請把下面的句子擴寫（至少加入兩個修飾的詞語）：　弟弟跑進教室。
答案：參考答案：滿頭大汗的弟弟，急急忙忙地跑進吵鬧的教室。
解析：擴寫是在主語、動詞或賓語前加上形容詞、副詞等修飾語，但不能改變原意。

1下列「」中的字，注音正確的是哪一個？

  2. (B)「孵」蛋 ㄈㄨ
  3. (C)以上皆正確
  4. (D)「繁」殖 ㄈㄢˊ
答案：(C)
解析：棲讀ㄑㄧ、孵讀ㄈㄨ、繁讀ㄈㄢˊ，三個都標對了，所以選「以上皆正確」。

  2. (B)生生不習
  3. (C)聲聲不息
  4. (D)生生不惜
答案：(A)
解析：「生生不息」的息是停止的意思，形容不斷地生長繁衍。
3請把注音寫成國字：溼地是候鳥重要的ㄑㄧ　ㄉㄧˋ（　　），我們要好好ㄅㄠˇ　ㄩˋ（　　）它。
答案：棲地、保育
解析：「棲地」的棲是木部（鳥停在樹上）；「保育」的育是肉部。
4下列哪一句屬於觸覺摹寫？
  1. (A)溪水冰涼地滑過我的腳背。
  2. (B)天空藍得發亮。
  3. (C)遠處傳來陣陣蟬鳴。
  4. (D)空氣裡有淡淡的青草味。
答案：(A)
解析：摹寫依感官分類：冰涼、滑過是皮膚的感受，屬觸覺；其餘依序為視覺、聽覺、嗅覺。
5「這片森林是無數生物的家。」這句話使用了什麼修辭？

  2. (B)設問
  3. (C)誇飾
  4. (D)排比

6請填入合適的關聯詞語：（　　　）我們願意改變習慣，環境（　　　）有機會變好。

解析：前面提出條件、後面說出結果，用「只要……就……」表示條件關係。

  2. (B)保育人員說「這片溼地是候鳥的驛站。」：
  3. (C)保育人員說：這片溼地是候鳥的驛站「」

8「候鳥每年往返數千公里」，句中的「往返」是什麼意思？
  1. (A)來回移動
