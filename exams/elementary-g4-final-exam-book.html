編輯說明

一、這本書是什麼。 這是期末考（第三次段考）的合訂題本，不是單張考卷。全書把國語、數學、自然、社會、英語五科放進同一本，每一科底下再依 康軒、南一、翰林、何嘉仁 分節出題，讓同一間安親班裡使用不同版本的孩子，可以各自翻到自己的那一節作答，老師只要備一本書。

二、題目從哪裡來。 全書題目 100% 自編，沒有抄錄任何學校的段考原卷。我們以「中小學題庫網（tcool.cc）」上北、中、南共 9 所國小的段考卷紀錄，來確認 各年級各科目實際採用的版本、段考次數與命題範圍，再依照這個範圍與十二年國教課綱自行命題，避免版權問題。各校版本對照見下一頁。

三、怎麼使用。 螢幕上點每一題下方的「解析」可展開答案與說明；按上方「列印 / 存成 PDF」時，解析會自動隱藏，印出來就是乾淨的作答題本，答案統一收在書末「解答本」。列印請用 Chrome 或 Edge，頁碼才會出現在頁尾。

四、進度提醒。 四上期末考的範圍以第九課之後與後段單元為主：數學為「角度、四邊形、面積與長條圖」，自然為「力與運動（玩具動起來）」，社會為「家鄉的節慶與文化資產」，英語為「季節天氣與綜合複習」。部分學校期末會加考全冊，本冊在解析中也會回顧前面單元的關鍵觀念，可搭配第一、二次段考題本一起複習。

五、配分建議。 每一節可獨立當成一份小考（滿分 100 分）；若要組成一份完整段考卷，建議：國語 30 分＋數學 30 分＋自然 20 分＋社會 20 分，英語另外單獨計分。

作答方式：選擇題把答案寫在括號內；填充題寫在橫線上；造句與改寫題請寫成通順完整的句子。期末範圍以第九～十四課為主，並複習全冊重點。
康軒版1-1　國語（康軒版）期末考
對應單元第九～十四課（含全冊複習）：字音字形、成語、修辭、關聯詞、短文閱讀　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「輝」煌 ㄏㄨㄟ
  2. (B)「凝」視 ㄋㄧㄥˋ
  3. (C)「鼓」勵 ㄍㄨˋ
  4. (D)「摩」擦 ㄇㄛˋ
答案：(A)
解析：輝煌讀ㄏㄨㄟ ㄏㄨㄤˊ。凝視的凝讀ㄋㄧㄥˊ、鼓勵的鼓讀ㄍㄨˇ、摩擦的摩讀ㄇㄛˊ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)全力以赴
  2. (B)全力以付
  3. (C)全立以赴
  4. (D)全力已赴
答案：(A)
解析：「全力以赴」的赴是前往、投入的意思，不能寫成「付」。
3請把注音寫成國字：他ㄈㄨˋ　ㄗㄜˊ（　　）打掃走廊，做得又快又ㄔㄜˋ　ㄉㄧˇ（　　）。
答案：負責、徹底
解析：「負責」的負是貝部；「徹底」的徹是彳部，指從頭到尾做到底。
4「掌聲像雷聲一樣響起。」這句話使用了什麼修辭？
  1. (A)譬喻
  2. (B)擬人
  3. (C)設問
  4. (D)排比
答案：(A)
解析：有喻體（掌聲）、喻詞（像）與喻依（雷聲），是典型的譬喻。
5「他做事總是（　　），從不投機取巧。」括號中填入哪一個成語最恰當？
  1. (A)腳踏實地
  2. (B)投機取巧
  3. (C)得過且過
  4. (D)敷衍了事
答案：(A)
解析：後句說「從不投機取巧」，前面要填意思相合的「腳踏實地」。
6請填入合適的關聯詞語：（　　　）平時多練習，比賽時（　　　）不會緊張。
答案：只要、就
解析：這是條件關係：前面提出條件，後面說出結果。
7下列哪一句沒有語病？
  1. (A)這場音樂會讓我印象深刻。
  2. (B)透過這場音樂會，讓我印象深刻。
  3. (C)經由這場音樂會，使我印象深刻。
  4. (D)在這場音樂會下，使我印象深刻。
答案：(A)
解析：「透過／經由／在……下」加「讓／使」會讓句子缺少主語，是常見語病。
8「一鼓作氣」這個成語的意思是什麼？
  1. (A)趁著氣勢一口氣把事情做完
  2. (B)慢慢來不著急
  3. (C)做到一半就放棄
  4. (D)邊做邊休息
答案：(A)
解析：典出擊鼓進軍，第一次擊鼓時士氣最盛，比喻趁勢一次完成。
9請把下面的句子擴寫（至少加入兩個修飾語）：　同學們打掃教室。
答案：參考答案：放學後，全班同學認真地打掃著堆滿紙屑的教室。
解析：擴寫是在主語、動詞或賓語前加上修飾語，但不能改變原本的意思。
閱讀測驗（第 10～11 題）
　　學校圖書館前有一台舊鋼琴，琴鍵有些泛黃，也有兩個鍵按下去沒有聲音。
　　午休時常有人坐下來彈，彈得好的、彈不好的都有。有一次一位同學彈到那兩個壞掉的鍵，停下來說：「這裡壞了。」旁邊的老師說：「那就繞過去彈，剩下的八十六個鍵還在。」
　　後來那台鋼琴始終沒有修好，卻幾乎每天都有人彈。
10這台鋼琴有什麼問題？
  1. (A)有兩個琴鍵按下去沒有聲音
  2. (B)完全不能彈
  3. (C)被搬走了
  4. (D)琴鍵全部壞掉
答案：(A)
解析：第一段寫「有兩個鍵按下去沒有聲音」，其他琴鍵仍可使用。
11老師說「剩下的八十六個鍵還在」，最主要想表達什麼？
  1. (A)把注意力放在還能做的事情上
  2. (B)壞掉的鍵不重要
  3. (C)鋼琴應該丟掉
  4. (D)不要再彈鋼琴了
答案：(A)
解析：面對缺陷時，與其停在壞掉的地方，不如善用還擁有的部分，這也是全文的主旨。

對應單元第九～十四課（含全冊複習）：字音字形、詞語辨析、摹寫、標點、短文閱讀　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)「翱」翔 ㄠˊ
  2. (B)「棲」息 ㄑㄧˊ
  3. (C)「覓」食 ㄇㄧㄢˋ
  4. (D)「孵」蛋 ㄈㄨˇ
答案：(A)
解析：翱翔讀ㄠˊ ㄒㄧㄤˊ。棲息的棲讀ㄑㄧ（一聲）、覓食的覓讀ㄇㄧˋ、孵蛋的孵讀ㄈㄨ（一聲）。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)生氣蓬勃
  2. (B)生氣篷勃
  3. (C)生機蓬勃
  4. (D)聲氣蓬勃
答案：(A)
解析：「生氣蓬勃」形容充滿活力，蓬是草字頭；「生機蓬勃」雖也常見，但標準用法為「生氣蓬勃」。
3請把注音寫成國字：候鳥每年ㄑㄧㄢ　ㄒㄧˇ（　　）數千公里，只為了尋找適合的ㄑㄧ　ㄉㄧˋ（　　）。
答案：遷徙、棲地
解析：「遷徙」指遷移；「棲地」是生物居住的環境。
4下列哪一句屬於視覺摹寫？
  1. (A)夕陽把天空染成一片橘紅。
  2. (B)遠處傳來陣陣鳥鳴。
  3. (C)風吹在臉上涼涼的。
  4. (D)空氣裡有淡淡的花香。
答案：(A)
解析：寫顏色屬視覺；其餘依序為聽覺、觸覺、嗅覺。
5「這片溼地是候鳥的驛站。」這句話使用了什麼修辭？
  1. (A)譬喻（隱喻）
  2. (B)誇飾
  3. (C)設問
  4. (D)排比
答案：(A)
解析：用「是」把溼地直接說成驛站，屬於譬喻中的隱喻。
6請填入合適的關聯詞語：（　　　）棲地被破壞，候鳥（　　　）可能不再飛來。
答案：如果、就
解析：這是假設關係：先假設情況，再說出可能的結果。
7下列句子的標點符號，使用正確的是哪一句？
  1. (A)解說員說：「請大家保持安靜。」
  2. (B)解說員說「請大家保持安靜。」：
  3. (C)解說員說：請大家保持安靜「」
  4. (D)解說員說，「請大家保持安靜」。
答案：(A)
解析：引述說話內容先用冒號再用引號，句號放在下引號的裡面。
8「絡繹不絕」這個成語，用來形容什麼？
  1. (A)來往的人或車輛接連不斷
  2. (B)一個人也沒有
  3. (C)事情做到一半停下來
  4. (D)動作非常緩慢
答案：(A)
解析：絡繹是連續不斷的樣子，常用來形容人潮或車潮。
9請把下面的句子縮寫成最精簡但保留主要意思的一句話：　每年秋天從北方飛來的候鳥，總會準時降落在這片寬闊的溼地上。
答案：參考答案：候鳥降落在溼地上。
解析：縮寫保留主語、動詞與地點，刪去修飾語（每年秋天、從北方飛來、總會準時、寬闊的）。
閱讀測驗（第 10～11 題）
　　每年十月，一群黑面琵鷺會飛越數千公里來到臺灣的溼地過冬。牠們白天休息，黃昏後才成群出來覓食。
　　三十多年前，全世界的黑面琵鷺一度不到三百隻。保育人員長期記錄、劃設保護區，農民也配合在特定時間放水，讓魚蝦聚集。數量才慢慢回升。
　　保育不是一個人做很多，而是很多人各做一點。
10黑面琵鷺主要在什麼時候覓食？
  1. (A)黃昏之後
  2. (B)中午
  3. (C)清晨天亮時
  4. (D)半夜十二點整
答案：(A)
解析：第一段寫「牠們白天休息，黃昏後才成群出來覓食」。
11「保育不是一個人做很多，而是很多人各做一點。」這句話想表達什麼？
  1. (A)保育需要許多人一起小小的配合與付出
  2. (B)保育只要靠專家
  3. (C)一個人就能完成保育
  4. (D)保育不需要農民參與
答案：(A)
解析：文中列舉保育人員記錄、劃保護區、農民配合放水，說明成果來自多方協力。

1下列「」中的字，兩個讀音相同的是哪一組？
  1. (A)「盛」開／「盛」大
  2. (B)「數」學／「數」一數

  4. (D)精易求精

解析：「精益求精」指已經很好還要更好，益是更加的意思。

4「集思廣益」這個成語，最適合用在什麼情況？

  2. (B)一個人默默決定
