康軒版1-1　國語（康軒版）第一次段考
對應單元第一～四課；記敘與議論類課文（形音義、成語、修辭綜合、語病、閱讀理解）　配分選擇每題 7 分、填充每格 5 分、寫作題 12 分
1下列「」中的字，注音正確的是哪一個？
  1. (A)自怨自「艾」ㄧˋ
  2. (B)「相」形見絀 ㄒㄧㄤˋ
  3. (C)「一」鼓作氣 ㄧˊ
  4. (D)「模」稜兩可 ㄇㄨˊ
答案：(A)
解析：自怨自艾的「艾」在此讀ㄧˋ（改正、治理之意），不讀ㄞˋ。相形見絀的相讀ㄒㄧㄤ、一鼓作氣的一讀ㄧˋ、模稜兩可的模讀ㄇㄛˊ。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)殷鑑不遠
  2. (B)走頭無路
  3. (C)負偶頑抗
  4. (D)如火如塗
答案：(A)
解析：走頭無路→走投無路（投，投奔）；負偶頑抗→負隅頑抗（隅，角落）；如火如塗→如火如荼（荼，白色茅草花）。只有「殷鑑不遠」正確。
3請把注音寫成國字：面對輿論的ㄓˊ　ㄧˊ（　　），他選擇以行動ㄏㄨㄟˊ　ㄧㄥˋ（　　）。
答案：質疑、回應
解析：「質疑」的質是提出問題；「回應」的應讀ㄧㄥˋ（回答之意），不要寫成「回映」。
4「時間是一把無情的刻刀，在每個人臉上留下痕跡。」這句話主要使用了什麼修辭？
  1. (A)譬喻兼擬人
  2. (B)設問
  3. (C)排比
  4. (D)類疊
答案：(A)
解析：把時間比作「刻刀」是譬喻；說它「無情」並會「留下痕跡」則帶有擬人的意味，屬於譬喻與擬人的綜合運用。
5下列哪一句有語病，需要修改？
  1. (A)為了避免不再發生意外，學校加強了安全宣導。
  2. (B)為了避免再發生意外，學校加強了安全宣導。
  3. (C)學校加強安全宣導，以免意外再度發生。
  4. (D)學校為了防止意外再度發生，加強了安全宣導。
答案：(A)
解析：「避免」和「不再」都含否定，兩個否定疊在一起意思會相反（變成希望意外發生）。應改為「避免再發生意外」。
6「他一向謙沖自牧，即使獲獎無數，也從不（　　）。」括號中填入哪一個成語最恰當？
  1. (A)自命不凡
  2. (B)實至名歸
  3. (C)精益求精
  4. (D)不以為然
答案：(A)
解析：前面說他謙虛，後面用「也從不」帶出相反的行為，要填自誇自大的詞，「自命不凡」正合。實至名歸是稱讚、精益求精是追求更好，都不合語意。
7請填入合適的關聯詞語：（　　　）我們願意改變習慣，減塑（　　　）不再只是口號。
答案：只要、就（或：如果、才）
解析：這是條件關係：前句提出條件，後句說出結果，可用「只要……就……」。若強調唯一條件，也可用「唯有……才……」。
8下列各組詞語，意思相反的是哪一組？
  1. (A)含蓄／直率
  2. (B)精緻／細膩
  3. (C)矛盾／衝突
  4. (D)豁達／開朗
答案：(A)
解析：含蓄是不直接說出，直率是有話直說，兩者相反。其餘三組都是意思相近的詞。
9請把下面的句子改成不改變原意的另一種說法（句型變換）：　沒有人不被他的毅力所感動。
答案：參考答案：每個人都被他的毅力感動。
解析：「沒有人不……」是雙重否定，等於全部肯定。改寫時要把語氣拉平但意思不變。
閱讀測驗（第 10～11 題）
　　有人主張，學校應該全面禁止學生攜帶手機；也有人認為，與其禁止，不如教會學生怎麼使用。
　　支持禁止的人指出，手機讓學生分心，也讓校園霸凌更容易發生。主張開放的人則回應：問題不在工具，而在使用的方式；把手機收走，並不會讓孩子自然學會自律，反而失去在有人指導時練習的機會。
　　真正的關鍵，或許不是「能不能帶」，而是「學校有沒有教」。一項規定若只有禁止而沒有教導，往往只是把問題推遲到孩子離開校園的那一天。
10本文對於「學校是否禁止手機」的立場，最接近下列哪一項？
  1. (A)完全支持全面禁止
  2. (B)認為重點在於學校有沒有教學生正確使用
  3. (C)主張學生應該無限制使用手機
  4. (D)認為手機和學習完全無關
答案：(B)
解析：最後一段是主旨句：「真正的關鍵，或許不是能不能帶，而是學校有沒有教」，作者把重點放在教導而非禁止。
11文中「把問題推遲到孩子離開校園的那一天」這句話的意思是什麼？
  1. (A)問題會自動消失
  2. (B)問題只是延後發生，並沒有真正解決
  3. (C)孩子畢業後就不會用手機
  4. (D)學校不需要負任何責任
答案：(B)
解析：「推遲」是往後延，作者指出只禁止不教導，孩子離開學校後仍然不會使用，問題並未解決。

閱讀測驗（第 10～11 題）
　　珊瑚看起來像石頭，其實是動物。牠們的身體裡住著一種叫「共生藻」的小生物，共生藻行光合作用製造養分供應珊瑚，珊瑚則提供共生藻安全的住所。
　　當海水溫度升高，這場合作會被打破：珊瑚會把共生藻排出體外，失去顏色，變成慘白的骨架，這就是「珊瑚白化」。白化並不等於死亡，如果水溫在幾週內回穩，共生藻可能回來；但如果高溫持續，珊瑚就會餓死。
　　一片珊瑚礁只占海洋面積不到百分之一，卻養活了將近四分之一的海洋生物。
10根據本文，珊瑚白化是怎麼發生的？
  1. (A)珊瑚被魚類吃掉
  2. (B)海水溫度升高，珊瑚把共生藻排出體外
  3. (C)珊瑚長得太快
  4. (D)海水變得太冷結冰
答案：(B)
