國語／數學／自然／社會／英語　共 51 題

國語1-1　國語　三年級上學期 第一次段考
對應單元第一～四課；主題多為四季景物與生活體驗（字音字形、筆畫部首、成語、造句、短文閱讀）　配分選擇每題 8 分、填充每格 5 分、造句 10 分
1下列「」中的字，注音完全正確的是哪一個？
  1. (A)「處」理事情 ㄔㄨˇ
  2. (B)「解」開繩子 ㄐㄧㄝ
  3. (C)「應」該 ㄧㄥˋ
  4. (D)「量」體溫 ㄌㄧㄤˋ
答案：(A)
解析：處理讀ㄔㄨˇ ㄌㄧˇ。解讀ㄐㄧㄝˇ、應該的應讀ㄧㄥ（一聲）、量體溫的量讀ㄌㄧㄤˊ（二聲），都是破音字要特別注意。
2下列詞語完全沒有錯別字的是哪一個？
  1. (A)座位安排
  2. (B)隨心所慾
  3. (C)再接再勵
  4. (D)名列前矛
答案：(A)
解析：隨心所慾→隨心所欲；再接再勵→再接再厲；名列前矛→名列前茅（茅是草字頭）。只有「座位安排」正確。
3請寫出「」中字的注音：秋天一到，楓葉「漸」漸變紅，山路上鋪滿了落葉，走起來沙沙作「響」。
答案：漸ㄐㄧㄢˋ、響ㄒㄧㄤˇ
解析：「漸」讀ㄐㄧㄢˋ（四聲），意思是慢慢地；「響」讀ㄒㄧㄤˇ（三聲），指發出聲音。
4「飛」這個字一共有幾畫？
  1. (A)七畫
  2. (B)八畫
  3. (C)九畫
  4. (D)十畫
答案：(C)
解析：「飛」共 9 畫，本身就是部首（飛部）。數筆畫時注意上面的「𠃌」和兩邊的羽狀筆畫都要分開數。
5「秋高氣爽」這個成語，最適合用來形容什麼？
  1. (A)秋天天氣晴朗涼爽
  2. (B)秋天颱風很多
  3. (C)秋天農作物歉收
  4. (D)秋天日夜溫差大到生病
答案：(A)
解析：秋高氣爽＝天空高遠、空氣清爽，形容秋天舒服的好天氣，常用來描寫適合出遊的日子。
6下列句子中，「的、得、地」用得正確的是哪一句？
  1. (A)他跑得很快。
  2. (B)他跑的很快。
  3. (C)他跑地很快。
  4. (D)他的跑很快。
答案：(A)
解析：動作後面接程度、狀態要用「得」（跑得很快）；「的」接名詞（我的書包）；「地」接在形容詞後修飾動作（慢慢地走）。
7請各寫出一個語詞：「觀」＿＿、「趣」＿＿。（不可寫課本上的同一個詞兩次）
答案：參考答案：觀察／觀賞；趣味／興趣
解析：這題考造詞。只要語詞通順、字寫對即可，例如觀光、參觀、樂趣、有趣等都算對。
8下列句子的標點符號，使用正確的是哪一句？
  1. (A)哇！今天的月亮好圓啊！
  2. (B)哇，今天的月亮好圓嗎。
  3. (C)哇？今天的月亮好圓！
  4. (D)哇。今天的月亮好圓，
答案：(A)
解析：「哇」是感嘆，後面用驚嘆號（！）；整句在讚嘆月亮圓，句末也用驚嘆號。感嘆句不能用問號或句號收尾。
9請用「雖然……但是……」造一個完整的句子。
答案：參考答案：雖然外面下著大雨，但是我還是準時到學校了。
解析：「雖然……但是……」表示前後意思相反（轉折）。前半句先說一個情況，後半句說出相反的結果。

　　奶奶愣了一下，笑著把其中一袋交給我。我們一起走了一小段路，她一直說謝謝。回到家，媽媽問我今天怎麼晚了十分鐘，我把事情說了一遍。媽媽沒有罵我，只摸摸我的頭說：「這十分鐘，花得很值得。」
10「我」為什麼比平常晚十分鐘回家？
  1. (A)在學校被老師留下來
  2. (B)幫老奶奶提菜
  3. (C)去便利商店買東西
  4. (D)在路上跌倒了
答案：(B)
解析：文中寫「我」幫奶奶提了一袋菜、一起走了一小段路，所以才晚了十分鐘。
11媽媽說「這十分鐘，花得很值得。」是什麼意思？
  1. (A)媽媽覺得我浪費時間
  2. (B)媽媽肯定我幫助別人的行為
  3. (C)媽媽希望我以後走快一點
  4. (D)媽媽要我以後別多管閒事
答案：(B)
解析：媽媽沒有責備，還摸摸頭稱讚，「值得」是肯定這十分鐘用在幫助人身上很有意義。

對應單元第一單元 植物的身體（觀察與記錄、根莖葉的功能、植物與環境）　配分選擇每題 8 分、填充每格 5 分、簡答每題 10 分
1植物製造養分的主要部位是哪裡？
  1. (A)根
  2. (B)莖
  3. (C)葉
  4. (D)果實
答案：(C)
解析：葉子裡有葉綠體，可以利用陽光、水和空氣製造養分，所以葉子是植物的「食物工廠」。
2植物的莖有兩個重要功能：一是支撐植物的身體，二是＿＿＿＿＿＿水分和養分。
答案：運送（輸送）
解析：莖像水管一樣，把根吸收的水分往上送到葉子，也把葉子製造的養分送到植物各部位。
3下列哪一種植物，我們吃的部位是種子？
  1. (A)花生
  2. (B)甘蔗
  3. (C)地瓜葉
  4. (D)芹菜
答案：(A)
解析：花生吃的是種子（豆莢裡面的部分）；甘蔗吃莖、地瓜葉和芹菜吃的是葉和葉柄。
4下列哪一項不是做科學觀察時應該有的態度？
  1. (A)仔細看清楚再記錄
  2. (B)覺得結果不好看就偷偷改資料
  3. (C)不確定的地方再觀察一次
  4. (D)把看到的畫下來並註明日期
答案：(B)
解析：科學紀錄必須誠實，看到什麼就記錄什麼。修改資料會讓別人得到錯誤的結論，是最要不得的行為。
5下列有關「根」的敘述，何者錯誤？
  1. (A)根可以吸收水分
  2. (B)根可以固定植物
  3. (C)有些植物的根會儲存養分
  4. (D)根可以行光合作用製造養分
答案：(D)
解析：製造養分是葉子的工作，根一般長在地下、沒有陽光，不能行光合作用。胡蘿蔔的根會儲存養分是正確的。
6觀察葉子時發現：楓葉的葉脈交錯成網子的樣子，這種葉脈叫做＿＿＿＿脈。
答案：網狀
解析：葉脈分兩大類：網狀脈（楓葉、榕樹葉）和平行脈（玉米、竹葉），可以用來當作植物分類的依據。
7把同一種小盆栽分成兩組，一組放在窗邊、一組放在黑暗的櫃子裡，其他條件都一樣。這個實驗最想知道什麼？
  1. (A)水量會不會影響植物
  2. (B)陽光會不會影響植物生長
  3. (C)土壤種類會不會影響植物
  4. (D)溫度會不會影響植物
答案：(B)
解析：實驗時只改變一個條件（有沒有陽光），其他條件都相同，這樣才知道結果是由陽光造成的。這叫做「公平的比較」。
8承上題，過了兩星期後，放在黑暗櫃子裡的那一組，最可能出現什麼結果？
  1. (A)葉子變得更綠更大
  2. (B)葉子變黃、莖細長而軟弱
  3. (C)開出更多花
  4. (D)完全沒有任何改變
答案：(B)
解析：缺少陽光無法正常製造養分，葉子會變黃，莖會因為向光生長而細長軟弱，整株植物明顯比較不健康。
