# 星光教學舞台 Starlight Teaching Stage

給**安親班老師**與**國小英文老師**的教學平台。打開網頁就能上課，不必安裝、不必連網、不必登入。

## 怎麼打開

直接用瀏覽器打開 `index.html` 就好（建議 Chrome 或 Safari）。
或在這個資料夾執行本機伺服器：

```bash
python3 -m http.server 8777 --directory teaching-site
```

## 四個頁面

| 頁面 | 檔案 | 做什麼 |
|---|---|---|
| 首頁 | `index.html` | 介紹、三步驟說明、入口 |
| 教學舞台 | `stage.html` | **核心**。選年級／科目／單元 → 五步驟流程＋計時器＋老師逐字腳本 |
| 英文教室 | `english.html` | 單字翻卡（會發音）、句型跟讀、看圖選字遊戲 |
| 課堂工具箱 | `toolbox.html` | 計時器、抽籤點名、快速分組、計分板、音效鈕、安靜倒數 |
| 資深老師工作台 | `pro.html` | **給有經驗的老師**。自己設計教學流程、寫腳本、存成課程庫、全鍵盤快速控制台 |

## 兩種老師，兩種用法

這個網站有兩條動線，刻意設計成相反的：

* **新手老師 → 教學舞台**：什麼都不用想，選年級科目單元，照著螢幕念、照著計時器走。
* **資深老師 → 工作台**：不給你腳本，讓你**寫腳本**。你設計的課程會自動出現在教學舞台最上方，
  掛著「🎓 資深老師課程」的標記，新老師點一下就能照著上。

也就是說：**資深老師定義標準，新老師執行標準。** 這是整個網站「把教學標準化」的機制。

### 資深老師工作台有什麼

1. **課程設計器** — 可從五科標準流程改編，也可從空白開始。每個步驟自訂名稱／時間／插圖，
   填四塊內容（老師這樣說／學生要做什麼／教具／成功標準），步驟可新增、刪除、上下移動，
   總時長即時累計（超過 90 分或少於 15 分會提醒）。
2. **課程庫** — 存好的課程可以「上這堂」（直接跳到教學舞台開始上）、編輯、複製、
   **印教案**（列印成一份紙本教案交給新老師）、刪除。
3. **交接與備份** — 整個課程庫可匯出成文字或 `.json` 檔，換電腦或給同事時匯入即可（匯入是「累加」不會蓋掉）。
4. **快速控制台** — 一個畫面看完整堂課，全鍵盤操作：
   `空白鍵` 開始／暫停、`←` `→` 換步驟、`1`–`9` 直接跳步、`R` 重新計時、`P` 列印教案。
   （在輸入框打字時快捷鍵不會誤觸。）

## 老師要改東西時，只要改一個檔

**`assets/js/data.js`** — 所有課程內容都在這裡，用記事本就能改：

* `UNITS` — 各年級各科的單元名稱。想新增單元，在陣列裡加一行字串就好。
* `FLOWS` — 五步驟的**老師逐字腳本**。每一步有四塊：
  * `say` — 老師可以直接念出來的話（`{unit}` 會自動換成老師選的單元名）
  * `do` — 學生要做什麼
  * `props` — 要準備的東西
  * `check` — 這一步算成功的標準
* `BANK` — 題庫概覽卡片。

改完存檔、重新整理網頁就生效，不需要重新編譯。

**`assets/css/site.css`** 最上面的 `:root` 是配色，改 `--primary`、`--sun` 等變數就能換整站顏色。

## 技術說明

* 純靜態 HTML／CSS／JS，**沒有任何外部相依**，離線可用。
* 22 張插畫都是自產的 SVG（`assets/img/`），放大不會糊。
* 音效由瀏覽器 Web Audio 即時合成，沒有音檔要下載；右上角可一鍵靜音（會記住）。
* 英文發音用瀏覽器內建語音合成（Web Speech API），支援慢／正常／快三種速度。
* 班級名單與自訂課程只存在老師自己的裝置（localStorage），不會上傳。
  換裝置請用工作台的「匯出／匯入」搬移。
* 手機、平板、電腦都可用；按 Ctrl/Cmd+P 列印時會自動隱藏按鈕與裝飾。
